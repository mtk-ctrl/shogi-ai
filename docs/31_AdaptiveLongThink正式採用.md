# AdaptiveLongThink 正式採用

## 目的

正式比較の標準を200msへ引き上げた後、難しい局面だけ最大1秒まで読む方式を本番実装する。

研究runnerでは「200ms探索を終了後、同一局面を最初から再探索」していた。正式実装ではそれを採用せず、**200msまで進めた反復深化探索をそのまま継続**する。TT、反復深化の前回最善手、現在のPV、探索統計を捨てない。

## 採用仕様

通常の正式対局条件は `go movetime 200` とする。

AdaptiveLongThink は既定ON。200ms時点で次のいずれかに該当する場合だけ、同一探索のdeadlineを `go movetime 1000` 相当まで延長する。

- 王手中
- 前回の自己評価から150cp以上悪化
- 直近2回の完了した反復深化で評価が150cp以上変動
- 直近2回の完了した反復深化で第一候補が変化
- 200ms時点でdepth2未完了
- 予約した長考枠の期限に到達

制約:

- 1局最大10回
- 24手目以降に長考枠を分散
- Book即決では使用しない
- MateAssistで強制詰みを証明した場合は使用しない
- 合法手が1手だけの場合は使用しない
- `usinewgame` で使用回数と前回評価をリセット
- 比較用に `setoption name AdaptiveLongThink value false` で無効化できる
- 固定200ms以外の `go` 条件には自動適用しない

## 100局の正式比較

同一バイナリで A=AdaptiveLongThink ON、B=OFF、双方 `go movetime 200`、OpeningBook ON、ExperienceCache OFF、先後を均等化して100局実施した。

5シャード各20局で実施し、各シャード内で先後10局ずつを確保した。

## 再スタート方式との比較

先行研究の「200ms後に同一局面を再スタートし、合計1秒まで読む」方式は100局で60勝37敗3分、得点率61.5%だった。

継続型は59勝38敗3分、60.5%でほぼ同水準を再現した。再スタートを必要とせず、既に得た探索情報を保持できるため、正式実装は継続型とする。

## 夜間対局

夜間自己対局も正式採用条件へ統一する。

- 通常対局: `go movetime 200` + AdaptiveLongThink ON
- 最大1秒・1局最大10回
- Nightly Book Learningは1バッチ10局から5局へ縮小し、終了時刻を守る
- Nightly Researchは思考時間増を考慮し、E0/E1を各100局、Position Bankを50局面、challengerを各20局へ縮小
- Diagnosis専用の shallow 50ms / deep 500ms は分析の固定尺度なので変更しない

## 採用判断

**正式採用する。**

固定200msより100局で60.5%を記録し、違法手0。先行の再スタート方式でも61.5%を確認しており、独立した2方式で同じ改善方向が出た。

今後の正式比較・夜間自己対局は200ms＋AdaptiveLongThinkを標準とする。
