# 外部エンジン対局基盤

## 目的

自己対局だけでは「自分自身にだけ有効な癖」を強化する可能性があるため、固定した外部USIエンジンを**物差し**として使う。

外部エンジンは教師ではない。探索・評価・定跡・推奨手をshogi-aiへ取り込まない。

## 境界

外部対局で使ってよいもの：

- 勝・敗・引分
- 得点率
- 違法手の有無
- 対局手数
- 応答時間
- 不具合解析のための棋譜

外部対局からshogi-aiへ入れてはいけないもの：

- 相手エンジンの評価値
- 相手エンジンのPV・候補手
- 相手の指し手を教師とする学習
- 相手との対局棋譜をOpening Book生成へ投入すること
- 相手との対局棋譜を評価関数学習・NNUE学習へ投入すること

`benchmarks/external_match.py` は相手の `info` 出力を読み捨て、`bestmove` だけを対局進行に使用する。結果JSONには `learning_eligible=false` と `opening_book_eligible=false` を明記する。

外部対局結果は `benchmarks/external-results/` に保存する。自己対局Book生成の既定入力である `benchmarks/results/` には保存しない。ランナー自身も `benchmarks/results/` 配下への出力を拒否する。

## 最初の対戦相手

最初はやねうら王の `YANEURAOU_ENGINE_MATERIAL` を使う。

これはやねうら王の通常探索を使うが、評価関数はNNUEではなく駒得中心である。目的はやねうら王の強さをshogi-aiへ移植することではなく、**別実装の固定相手**を得ることである。

初期設定：

- やねうら王のソース版を特定commitへ固定
- `YANEURAOU_ENGINE_MATERIAL`
- `MATERIAL_LEVEL=1`
- `Threads=1`
- `USI_Hash=16`
- `USI_OwnBook=false`
- 相手は固定nodes
- shogi-aiは `go movetime 50`
- shogi-aiの `ExperienceCache=false`
- まずはOpening BookもOFFにしてコア探索を測る

## YaneuraOu Material Level 1～100

長期的な進歩を「現在Lv.いくつか」で追えるよう、やねうら王material版の1手あたり探索nodesを100段階に固定する。

`benchmarks/external_levels.py` が唯一の換算規則である。

- Lv.1 = 10 nodes
- Lv.100 = 1,000,000 nodes
- その間は対数目盛りで等間隔
- 約20レベル上がるごとに相手の探索量が約10倍になる

代表値：

| Level | nodes/手（概数） |
|---:|---:|
| 1 | 10 |
| 21 | 102 |
| 41 | 1,048 |
| 60 | 9,545 |
| 80 | 97,701 |
| 100 | 1,000,000 |

このLevelは一般的な棋力段級位やEloではなく、**このプロジェクト専用の固定外部ベンチマーク尺度**である。やねうら王のバージョン、material版、Threads、Hash、定跡OFF等を固定して初めて世代比較に使える。

### 到達レベルの扱い

少数局のスモーク試験は「暫定」であり、到達認定には使わない。

基本運用：

1. まず20局程度で複数Levelを試し、互角帯を探す。
2. 候補Levelを100局、先後50局ずつで確認する。
3. 得点率55%以上かつ違法手0なら「Clear」。
4. 得点率45%以上55%未満は「Equal zone」。
5. 得点率45%未満は「Not clear」。
6. 最高Clear Levelを、その時点の外部基準到達値としてREADME/journalに残す。

100局で細かいLevel差が統計的に完全分離できるわけではないため、1～2レベルの上下は過度に解釈しない。大きな節目や正式版では200局再確認を行ってよい。

最初の4局スモークでは約100 nodes（Lv.21相当）に3勝1敗、違法手0だったが、局数不足のため**Lv.21認定とはしない**。

## なぜ同じ50msにしないか

異なるエンジンでは1msあたりの探索量が大きく違う。外部基準戦の目的は「同じ計算量で公平な競技」をすることではなく、**同じ相手・同じ条件に対して新版がどれだけ改善したか**を継続測定することである。

したがって、相手は固定nodes、shogi-aiは通常採用試験と同じ50msを基本にする。

## 2種類の外部基準

### Core benchmark

Opening Book OFF、Experience Cache OFF。

探索・評価・MateAssist等の本体性能を比較する。自己対局Bookが別チャットで更新されても影響を受けにくい。

### Full-engine benchmark

Opening Book ONを含む実戦設定。

定跡も含めた「現在の完成版」の総合力を測る。Coreとは結果を混ぜない。

外部レベルの主指標はCore benchmarkとする。Full-engine benchmarkは完成版全体の実戦性能確認として併記する。

## 将来

1. material版やねうら王で現在の互角帯を探し、最初の正式Clear Levelを決める。
2. 各主要版で最高Clear Levelを更新する。
3. Lv.100が現実的に近づいた時点でmaterial尺度の卒業を検討する。
4. その後に限り、NNUE版やねうら王を別の上位尺度として追加してよい。

NNUE版と戦う場合でも、その評価値・PV・棋譜を教師データへ流さない限り、やねうら王の評価知識をshogi-aiへ取り込むことにはしない。
