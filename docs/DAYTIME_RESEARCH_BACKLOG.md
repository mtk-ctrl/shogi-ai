# Daytime Research Backlog

## 位置付け

この文書は **夜間対局システムの実装課題ではなく、日中にオーナーとChatGPTが一つずつ議論・設計・実装する研究課題** を管理する。

Nightly再開後は経験生成・診断・登録済み仮説の検証を担わせる設計である。現在は変革期の優先課題へ開発を集中するため、R30に従い夜間の定期対局を一時停止している。以下の研究を「夜間で既に自動実行される」とは扱わない。
以下の新しい「考え方」を、将来の夜間処理が勝手に簡易実装して置き換えてはいけない。

## Engine — 評価システム

### E1 Influence（効き・盤面支配）

検討事項:
- 効きの広さと質
- 攻めの効き / 守りの効き
- 重要マスへの効き
- 同一地点の数的優位
- 敵陣・中央・玉周辺の価値差
- AttackMapとの責務分離
- Pressure / Dangerとの二重計上回避
- 安い歩打ち等で形式的にPressureだけ増やす「評価の抜け道」がないか

検証:
- 固定局面
- Influence OFF ablation
- Champion paired match
- control-conflict局面での局面別成績

### E2 Coordination（駒の連携・形）

検討事項:
- 相互防御
- 浮き駒・孤立駒
- 玉と守備駒の連結
- 攻撃駒の共同作用
- グラフ表現の必要性
- 玉の安全は「直近8マス」だけで完結させず、その外周（概ね次の16マス）も別レイヤとして扱う
- 玉からの距離に応じて守備価値を減衰させ、近接守備と外周守備を分離して診断する
- 同じ守備配置でも、敵の攻撃可能方向・大駒の射線・歩の衝突地点によって価値を変える
- 居玉と、矢倉等で一方の側面から攻められにくい玉形を同じ「玉周辺駒数」で評価しない
- 「囲いの名前」を認識すること自体を目的にせず、玉周辺の連結、外周の壁、侵入口、開いている側面、敵攻撃駒の到達可能性を機械的特徴へ分解する
- 玉周辺の守備評価は Safety との二重計上を避け、Coordination は主に「守備駒同士がどう支え合っているか」を担当する

機械判定の初期案:
- king-zone を距離1（8近傍）/ 距離2（その外周）に分ける
- 各zoneで味方の効き枚数・最安守備駒・相互防御数・孤立駒数を数える
- 敵側の効き・大駒射線・前進可能な歩/銀/桂等から「攻めが到達しやすい側」を推定する
- 玉の左右・前後を分け、攻撃到達性の低い側の守備不足は軽く、侵入口が開いている側の不足は重く扱う
- 固定局面では「居玉」「囲い途中」「矢倉型で片側が閉じた形」「両側から攻められる形」を分けて比較する

### E3 Mobility / Freedom の拡張

現行Activityは安全な移動先数を中心にしている。以下を別概念として扱うか検討する。
- 有力合法手数
- 拘束駒
- 大駒の通り
- 玉の逃げ道
- 成り余地
- 持ち駒の有効な打ち場所
- 角道・飛車筋を開ける「射線開通」の価値
- 自駒ブロッカーを動かした後に増える将来の可動域
- 1手後・数手後の選択肢増加を測る Potential / Latent Mobility

実戦観測:
- 2026-10-06の家族対局で、角道を開ける等の「今すぐ駒得ではないが将来の選択肢を増やす手」が弱く見えた。現在Mobilityと潜在Mobilityを分離して固定局面で再現する。

### E5 Flexibility / Irreversibility

- 歩突き、桂跳ね、駒打ち、交換による選択肢減少

### E8 評価値の校正

- 評価値と自己対局実勝率の対応

- featureごとの過大/過小評価検出

### E9 Promotion / Transformation value audit

現行 `piece_value()` には成駒価値があり、歩・香・桂・銀の成駒は600、馬・龍は元の角・飛車より+200としている。また歩・角・飛車は同一移動で成/不成が両合法なら成を残す `PromotionPolicy` がある。したがって「成り価値がない」と決めつけず、実戦で弱く見える理由を監査する。

検討事項:
- 成り前後の静的評価差が意図どおり出るか
- 馬・龍の+200が効き・自由度の増加に対して十分か
- 他featureに成り価値が埋もれていないか
- 50ms等の短時間探索で将来の成り価値を回収できるか
- 静止探索が成り手を扱うことで、短い本探索の弱点をどこまで補えるか
- 銀・桂・香のように動きが変質する成りと、歩・角・飛車の単調に能力が増える成りを分離するか

検証:
- 「成る/成らない」「成りに向かう/別手」の固定局面セット
- 評価内訳のbefore/after比較
- Promotion value ablation / parameter challenger
- 実戦で違和感が出た局面の再現

### E10 Material vs Positional Value（駒得と位置価値）

- 駒得をどこまで絶対視し、位置価値がどこから上回るか
- 駒を捨ててでも得る攻撃・玉安全・Space・主導権の価値
- 交換損とテンポ・射線開通・成り・攻め継続の交換条件
- Materialと他featureの二重計上・過大評価を避ける
- 駒価値そのものを局面フェーズで変える必要があるか

検証:
- 同一Materialで位置だけ違う固定局面
- Material差はあるが深い探索では逆転する局面
- Material OFF/縮小 ablationは研究用に限定し、通常採用はpaired matchで確認

### E11 Idle Pieces / Attacking Mass（遊び駒・攻め駒不足）

- 自陣で働いていない遊び駒の検出
- 戦場へ到達可能だが現在は働いていない駒と、構造上使えない駒の区別
- 攻めに参加している駒数・価値・到達時間
- 攻め駒不足のままPressureだけ高くなる誤評価の防止
- Coordination / Mobility / Spaceとの責務分離

- 千日手回避を目的に悪手を選ばせず、勝てる局面で勝ち切る能力を改善する
- 終盤の評価・探索・詰み探索のどこがボトルネックかDiagnosisで切り分ける

## 進め方

原則として一つの仮説について以下を守る。

1. 日中に仮説と責務を議論する。
2. 固定局面で狙った能力を確認する。
3. 実験版をmanifestへ登録する。
4. R20/R21に従ってChampionとpaired validationする。Nightlyが再開済みなら夜間基盤を利用してよいが、停止中は手動Actions等で行う。
5. Ablationで寄与を確認する。
6. 外部benchmarkは別軸で測る。
7. 採否・理由・次課題をjournal/開発史へ残す。

複数の新概念を一度に本番へ入れ、何が効いたか分からなくすることを避ける。ただし研究上の相互作用を調べるため、単独効果確認後に組合せ実験を行う。
