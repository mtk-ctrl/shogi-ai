# 詰将棋探索

## 位置付け
この文書は詰み探索とMateAssistの技術設計を説明する。
比較対局の持ち時間・採否条件はここでは決めず、`docs/rules/R20_対局・比較・統計.md` を正本とする。
整理前の詳細な実装史は `docs/archive/pre-router/19_詰将棋探索.md` に保存した。

## 専用 go mate
攻め方は王手だけを候補にし、受け方は合法な全応手を読む。
現行の専用探索上限は7 plyである。
探索範囲内で詰みを証明できない場合は、それを「詰みなし」と断定せず `checkmate timeout` とする。

## ルール層との境界
合法手、王手判定、着手・undo、千日手等はルール層を利用する。
詰みをどう探索し、どの候補を優先するかは自作する。

## 通常 go の MateAssist
時間制限付き通常探索では、小予算の攻守MateAssistを使う。
現行の常時確認は1手・3手相当で、強制詰みを証明できた場合に利用する。
専用 `go mate` の7手探索と、通常対局で常時使う深さを混同しない。

## 性能履歴
v0.0.16〜v0.0.19の軽量化、fast path、固定問題結果、旧50ms比較はarchiveの原文とjournalを参照する。これらの旧比較条件を現在の一般Ruleへ昇格させない。
