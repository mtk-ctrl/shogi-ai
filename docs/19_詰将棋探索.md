# 詰将棋探索

## 位置付け
この文書は詰み探索とMateAssistの技術設計を説明する。
比較対局の持ち時間・採否条件はここでは決めず、`docs/rules/R20_対局・比較・統計.md` を正本とする。
整理前の詳細な実装史は `docs/archive/pre-router/19_詰将棋探索.md` に保存した。

## 専用 go mate
攻め方は王手だけを候補にし、受け方は合法な全応手を読む。
現行の専用探索上限は7 plyである。
探索範囲内で詰みを証明できない場合は、それを「詰みなし」と断定せず `checkmate timeout` とする。

## ルール層との境界
合法手、王手判定、着手・undo、千日手等はルール層を利用する。
詰みをどう探索し、どの候補を優先するかは自作する。

## 通常 go の MateAssist
時間制限付き通常探索では、小予算の攻守MateAssistを使う。
現行の常時確認は1手・3手相当で、強制詰みを証明できた場合に利用する。
専用 `go mate` の7手探索と、通常対局で常時使う深さを混同しない。

## v2.0.11採用：10万問の詰み学習予測器

16特徴量の予測器で最大7手の詰み探索を優先するかどうかを判断する。採用モデルは `engine/models/mate-learning-v2-100k.txt` をビルド時に検証しバイナリへ内蔵する。モデルの出力は詰みの証明ではなく、確定着手は既存 `MateSearch` が合法な強制詰みを証明した場合に限る。

標準200ms対局は成熟度0～33では専用詰み補助の時間0msとし、34以上では成熟度・玉の危険度・学習予測により時間枠を配分する。学習ON・成熟度配分ON・aggressive配分を標準とする。専用 `go mate` の7手探索と通常局面への時間配分を混同しない。比較はrun `38108459754`、本人による採用判断は `docs/decisions/2026-10-11_詰み10万問学習モデル正式採用.md`。
