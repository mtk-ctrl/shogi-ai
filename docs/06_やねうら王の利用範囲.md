# やねうら王の利用範囲

## 方針

このプロジェクトでは、やねうら王を「将棋というゲームを正しく扱うためのルール層」として利用する。

目的は、将棋ルールそのものを一から再実装することではなく、その上で動く思考部分を自分たちで段階的に強化し、将棋AIの仕組みを理解することである。

## やねうら王から利用する範囲

当面は次を利用対象とする。

- 盤面・手番・持ち駒の管理
- SFEN/USI局面の読み込み
- 合法手生成
- 着手の適用と局面更新
- 成り・不成
- 駒打ち
- 二歩、行き所のない駒、打ち歩詰め等の反則判定
- 王手・王手放置の判定
- 詰み・終局に関係する基本的なルール判定
- 千日手・連続王手等、対局成立に必要なルール処理

## 原則として自作する範囲

次は、学習対象として自分たちで段階的に作る。

- 合法手の中からどの手を選ぶか
- 駒得などの局面評価
- minimax
- αβ探索
- 手の並べ替え
- 置換表
- 時間配分
- 高度な評価関数
- NNUE等の学習型評価
- 自己対局・強化学習

必要に応じて将来やねうら王の実装を参考にするが、最初から強い探索・評価をそのまま利用しない。

## 境界のイメージ

```text
ShogiDroid2
    ⇅ USI
自作AI
    ├─ やねうら王のルール層
    │    ├─ 局面管理
    │    ├─ 合法手生成
    │    ├─ 着手適用
    │    └─ ルール判定
    │
    └─ 自作の思考層
         └─ 合法手の中からどれを選ぶか
```

## v0.0.2の実装

やねうら王のルール層から現在局面の合法手一覧を取得し、その中からランダムに1手を選んでUSIの `bestmove` として返す。

この段階では強さは目的としない。実装と検証結果は `07_ルール層の分離設計と検証.md` に記載する。
不成・千日手も上流実装を利用し、上流の評価・探索は組み込まない。
