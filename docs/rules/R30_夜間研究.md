# 夜間研究

## 位置付け
NightlyはBook専用処理ではなく、雲路全体の研究基盤として扱う。
一晩の開始時点の `main` をChampionとして固定し、原因の異なる変更を混ぜない。

## 現在の自動化状態
Book / Experience方針がH10で保留中のため、従来の `nightly-research.yml` と `nightly-book-learning.yml` は `docs/hold/workflows/` へ退避し、自動scheduleを停止している。
H10の結論後に、R21のrunner運用を満たす1本のNightly基盤として再設計する。

## 実行
- 開始時刻の現行記録は00:05 JSTである。対局は05:00 JSTまでに終了し、集計・保存はその後に行ってよい（2026-10-07、問5本人確認）。
- 時間枠内で完了できる量に調整し、05:00を越えて対局を続ける前提で局数を固定しない。夜間処理の再開可否と開始時刻の再確認は、この終了時刻の決定とは別に扱う。
- 対局条件はR20、runner利用はR21に従う。
- 同一開始条件では先後を対にすることを基本とする。
- 登録されていない新しい評価概念を夜間処理が勝手に簡易実装しない。
- 未実装能力は別機能で代用したことにせずcapability gapとして報告する。
- Engine / strategyを夜間結果だけで自動的にmainへ昇格させない。

## Book / Experience
BookとExperienceの役割分担、更新、永続化、自動昇格、外部対局由来Experienceは現在H10で保留中である。
Nightly関連作業でこれらの方針を新たに決めたり、既存挙動を方針決定とみなしたりしない。

Nightlyの構造とフェーズ説明は `docs/NIGHTLY_RESEARCH_SYSTEM.md` を参照する。
