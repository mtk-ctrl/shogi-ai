# 外部AI・梯子・Floodgate

## やねうら王の利用境界
雲路本体へ利用してよいのはルール層である。
利用対象は合法手生成、局面管理、着手適用、王手・成り・持駒・千日手等のルール処理。
探索、評価、move ordering、TT、詰み探索、戦略、学習は自作する。

外部対戦相手として、やねうら王自身の探索を動かすことは別用途として許容する。

## 外部AIの扱い
外部AIは棋力測定・弱点発見の物差しであり、相手の評価値・PV・候補手を雲路の教師として取り込まない。
外部AIの指し手一致率を目的関数にしない。

外部対局由来局面に対するExperienceの扱いはH10で保留中であり、ここでは決めない。

## 人間との対局・人間の棋譜の学習利用
2026-10-07の問7本人回答により、人間との対局を学習に使う対象はオーナー本人との対局に限る。
プロ・アマ等の他人の棋譜や、本人以外の家族との対局を学習へ取り込まない。本人が提供したファイルであっても、他人同士の棋譜は本人との対局ではない。
学習利用前に出所と対局者を確認し、本人との対局か不明な棋譜を推測で対象にしない。
この設問は人間の棋譜の利用対象を確認したものであり、自己対局の方針を変更する指示とは扱わない。
学習対象の許可と、実戦手・勝敗を無条件に正解ラベルへすることは別である。記録・活用の制約はR25、Book / Experienceの未決の責任分担・更新方式はH10に従う。
本人原文と適用範囲は `docs/decisions/2026-10-07_会話による運用確認.md` の問7に記録する。

## Material梯子
やねうら王Material Level 1〜100の換算は `benchmarks/external_levels.py` を実装上の基準とする。
外部Benchmarkの持ち時間・nodes等は一般のR20正式比較条件とは別の固定尺度であり、目的なく200msへ統一しない。
梯子を実行するときはR20・R21・`docs/23_外部エンジン対局基盤.md`も読む。

## Floodgate
- 接続層から雲路本体の評価・探索方針を変えない。
- `--live` 等の明示的な実参戦指定なしに本番接続しない。
- 認証・trip等の秘密情報をGitHubへ保存しない。
- 実参戦前に外部仕様を再確認する。
- Book / Experienceの学習対象可否はH10の保留を優先する。
