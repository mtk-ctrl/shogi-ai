# v0.0.4 2手探索（2-ply minimax）

## 目的

v0.0.3は、各合法手を指した直後の駒得だけを比較するため、「駒を取れるが次にもっと大きな駒を取り返される」手を避けられなかった。

v0.0.4では駒価値を一切変更せず、相手の応手を1手だけ追加して読む。これにより、強さの変化を「評価関数の変更」ではなく「先読みの効果」として測定する。

## アルゴリズム

現在局面で自分の合法手をすべて列挙する。各候補手について、着手後の相手の合法手をすべて列挙し、相手が自分にとって最も不利な応手を選ぶと仮定する。

```text
自分の候補手 A
  ├─ 相手の応手 a → 評価 +300
  ├─ 相手の応手 b → 評価 -900  ← 相手はこれを選ぶと仮定
  └─ 相手の応手 c → 評価 +100
  => A の評価 = -900

自分の候補手 B
  ├─ 相手の応手 a → 評価 0
  └─ 相手の応手 b → 評価 -100
  => B の評価 = -100

自分は B を選ぶ
```

これは深さ2 plyのminimaxである。自分の手で最大化し、相手の手で最小化する。

## 評価関数

通常局面の評価はv0.0.3と完全に同じ `material_black()` を使う。駒価値も変更しない。

終局局面だけは駒得より優先する。

- 自分の勝ち：`+100000000`
- 引分：`0`
- 自分の負け：`-100000000`

これにより、駒得が大きくても詰まされる手を選ばず、駒得が少なくても即詰みなら優先できる。

## v0.0.3との境界

- やねうら王：盤面、合法手、着手、反則、終局判定
- 自作v0.0.3：駒価値・静的評価
- 自作v0.0.4：2-ply minimax

やねうら王の探索・評価・定跡・置換表・NNUEは利用していない。

## 固定テスト

v0.0.3で再現する「毒歩」の局面を回帰テストにした。

- v0.0.3：飛車で歩を取る
- 相手：その飛車を飛車で取り返す
- v0.0.4：相手の取り返しまで読むため、その手を避ける

さらに、即詰みが通常の駒得より優先されること、探索後に盤面・手番・千日手履歴が完全に戻ること、`searchmoves`制限、seed再現性も検証する。

## 計算量

初期局面のように双方がおよそ30手ずつ候補を持つ場合、概ね30×30で約900の葉を評価する。v0.0.3より大幅に重くなる。

100局比較のCI実測では、1手平均応答時間はv0.0.4が22.067ms、v0.0.3が0.499msで、約44倍となった。

この増加を次のPhase 4「αβ探索」で削減する。まず枝刈りなしminimaxを作ったことで、αβが同じ答えをどれだけ少ない計算で出せるか比較できる。
