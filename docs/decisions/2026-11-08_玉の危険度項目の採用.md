# 玉の危険度の追加項目（EvalKingExt）の正式採用

日付: 2026-11-08
対象: KUMOJI v2.0.27（v2.0.26からの更新）

## オーナーの判断
- AIが、玉の危険度の新項目を足した版が現行v2.0.26に対し400局で62.1%（247勝150敗3分、近似95%区間 約57〜67%）と有意に強いと報告し、採用を提案した。
- オーナーの原文: 「採用してください」（2026-11-08）
- 解釈: EvalKingExt（係数 207,7,252,11,263,67,94、`EvalKingExtScale=100`）を既定にする。玉の前進は含めない。

## 採用内容
- 玉の周りの7つの量（相手の利き、味方の守り、弱い升、相手の持ち駒の価値、守りのない被攻撃升、玉近くの相手の駒、弱い升×持ち駒枚数）を、後手玉−先手玉の差に係数を掛けて位置評価へ加算する。成熟度20から60にかけて直線的に効かせる。
- 実装: `engine/strategy/evaluation_king_ext.h`、`engine/strategy/evaluation.h`、`engine/strategy/evaluation_params.h`（既定 scale 100・係数）、`engine/strategy/phase_weights.h`、`engine/main.cpp`（USI `EvalKingExtScale`・`EvalKingExtCoef`、版名v2.0.27）。研究ブランチ `research/king-features-20261108`（1e6955b）をmainへ統合。legacy_v1・material_onlyでは無効。

## 根拠と留意点
- 先に、現行評価に項目を足すと勝敗予測の誤差が成熟度50以上で約4%、67以上で約5%下がることを自己対局1,199局で確認した（重みの再当てはめは差がほぼ0）。
- 対局: A=EvalKingExt、B=v2.0.26（同一commit）、400局、`go movetime 200`。247勝/引分3/150敗、違法手0、平均97.5手。
- 注意: 係数は、v2.0.26系の自己対局データへ当てはめた値で、外部エンジンや人間相手の強さは未測定。外部ラダーでの確認は未実施。
