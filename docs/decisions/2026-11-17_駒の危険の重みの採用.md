# 駒の危険の重みを上げる（v2.0.33）

日付: 2026-11-17　対象: KUMOJI v2.0.33（v2.0.32からの更新）　採用方式: 自動採用（勝敗差+12以上かつ違法手0。[自動採用と自走運用](2026-11-17_自動採用と自走運用.md)）

## 変更
駒の危険（自分の取られそうな駒の損失の評価）の段階別重みを、序盤168→300、中盤221→700、終盤150→250へ。他の配点・探索・時間配分は変更なし。`engine/strategy/phase_weights.h` の3行。版名をv2.0.33へ。

## 根拠
- 発端: 急落（評価が数手先の結果を見誤る）は読みの深さより先にあり、枝刈り・手順の工夫では直らなかった（journal 02）。読みで届かない損を評価に持たせる方向。
- 当てはめ: Floodgate自戦81局の勝敗に、駒以外の9軸の段階別重みを当てはめると、未学習の対局での勝敗予測は改善した（log-loss 0.593→0.504〜0.546）が、そのまま自己対局に入れた2案は41勝67敗で負けた。2案に共通して大きく動いたのは中盤の「駒の危険」（221→約1,100〜2,100）だけだったので、この軸だけを、当てはめ値よりかなり控えめに動かした。
- 検証: 現行版v2.0.32に対し自己対局108局（6シャード、1手200ms、AdaptiveLongThink・局面知識ON）で**65勝43敗（+22、60.2%）**、違法手0（run 44088519554）。

## 注意（後で見直す点）
- 変更値（300・700・250）は、当てはめ値を人手で控えめにしたもので、最適化した値ではない。本数は1本のみ（+22は基準の+12を上回る）。
- 自己対局は雲路どうしの比較で、強い相手（Floodgate）での効果は未確認。Floodgateでの急落（評価+300以上から0以下への落ち）の頻度が下がるかを、次の回以降の対局で見る。
- 戻し方: `StageOpening/Middle/End` の危険の値を168/221/150へ戻す。
