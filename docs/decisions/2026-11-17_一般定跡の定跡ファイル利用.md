# 一般定跡を定跡ファイルとして雲路に使わせる（2026-11-17）

## 本人発言
「雲路が行き詰まっています。定跡を入れようかと思うけど、将棋ai開発で一般的に定跡は具体的にどういうふうに扱われてて、どう保存読み込みしてるかを調べてほしい。そのうえで、たとえば相掛かりとかの一般的な定跡をひとつ雲路に使わせて、同じように定跡を作れるようにしてほしい。」

## 確定した範囲
- 将棋AIで標準的なやねうら王形式（`.db`）の定跡ファイルを、雲路が読んで指せるようにした（自作の読み込み器、USI `BookFile` / `BookMoves` / `BookSelect`）。
- 人間の一般的な序盤定跡（相掛かりの基本形）を本人依頼で手入力し、最初の定跡 `books/aigakari.db` とした。R50に「定跡ファイルとして指すことに限り可、学習教師・他人の棋譜の取り込みは不可」として追記。
- 定跡ソース（1行1手順）から `.db` を作るツール `tools/book/make_book.py` を追加。雲路に各定跡手を読ませて評価値・深さを書く機能つき。
- 既定は不使用（`BookFile=<empty>`）。Floodgate等で有効にするかは本人判断（未決）。

仕様：`docs/41_定跡ファイル（やねうら王形式）.md`。
