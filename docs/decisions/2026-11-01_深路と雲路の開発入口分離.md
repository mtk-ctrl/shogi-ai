# 深路と雲路の開発入口を分ける

本人依頼：「まずはGitHubの深路と雲路を分けて理解して、深路の強化」「可能であれば雲路のルーターとルールを参考に、深路用のルーターとルールを整備」「将棋ai開発のルーターも適切に修正」。

確定範囲：深路はNNUEによる自己学習を主軸とする独立AI。深路側にF00/F10/F20/F30とD17を整備し、雲路ルーターから誤ってR系Rule一式を適用しないよう対象分岐を追加する。

雲路のR系Ruleの適用条件・評価配点・モデル・正式エンジン・実行中の研究は変更しない。深路の研究用暫定更新の権限を雲路へ拡張しない。共通Drive入口も同じ二系統へ案内する。

検証：check_doc_router.py / check_workflow_inventory.py / check_match_workflows.py / check_current_claims.py。結果は変更commitの検証記録を参照。
