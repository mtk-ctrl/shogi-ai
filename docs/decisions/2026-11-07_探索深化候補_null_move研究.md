## 範囲と制約
- 実装は自前（Position::pass_position + strategy層の探索方針）。やねうら王/Stockfishの探索コードは使わない（R50）。
- 既定値は無効（SearchPruneMask=0）。無効時は従来探索と同じ（完走深さ2.917で一致を確認）。
- 一度に一つだけ変更（R10）。

## 実装
- `Position::pass_position`: SFENの手番だけ反転した新Positionを作る。王手中は不可。履歴は持ち越さない。
- `search()`: PVでない節点・非王手・直前がnullでない・詰みスコア付近でない・静的評価が裏付ける場合に、深さ depth-1-R で null window 探索。fail-high（最大側 >=beta、最小側 <alpha）でカット。カット時はTTに保存しない。
- USIオプション: SearchPruneMask(bit1=null move) / NullMoveReduction / NullMoveMinDepth。

## 検証結果（サンドボックス、go movetime 200、24局面×2回、PositionKnowledge ON）

- 返した手はすべて合法。ただし棋力は未測定。完走深さの増加は+0.2程度で小さい。
- 理由の仮説: 深さ3前後では reduced depth が0〜1になり、null moveで省ける部分木が小さい。LMR/futilityの方が深さ3〜4で効く可能性がある。
- 注意: 完走深さ・ノード数は棋力の代理に過ぎない（2026-10-05の教訓）。判断は200局以上の対局（R20条件）で行う。
