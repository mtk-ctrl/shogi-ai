# 探索パッケージの正式採用

日付: 2026-11-08
対象: KUMOJI v2.0.25（v2.0.24からの更新）

## オーナーの判断
- AIが、パッケージ（探索のみ）が現行v2.0.24に対し400局で67.0%、評価項を足した版が65.3%だったと報告し、採用範囲を問うた。
- オーナーの原文: 「パッケージで採用です。」（2026-11-08）
- 解釈: 探索パッケージ全体を既定にする。評価項（EvalKingDrop）は上積みが見えないため含めず、既定オフの研究コードとして残す。

## 採用内容
- 置換表共有（SearchSharedTT=1）、null move（SearchPruneMask bit 1、縮小幅2、最小深さ2）、reverse futility（bit 8、深さ3以下、余裕350cp×深さ）、攻撃射線の事前表（SearchReuseMask=14）、評価キャッシュ2^20件。
- 既定値: SearchPruneMask=15、SearchReuseMask=14、SearchSharedTT=1、NullMoveMinDepth=2。版は v2.0.25。
- 実装: `engine/strategy/iterative_search.h`、`engine/strategy/shared_transposition_table.h`、`engine/strategy/search_research.h`、`engine/strategy/evaluation*.h`、`engine/main.cpp`。研究ブランチ `research/package3-20261107`（707c081）をmainへ統合。

## 根拠
- 対局（A=パッケージ、B=v2.0.24、各200局×2、`go movetime 200`）: 探索のみ 267勝/引分2/131敗（67.0%）、探索＋EvalKingDrop 260勝/引分2/138敗（65.3%）。
- 200ms・24局面の平均完走深さ: 現行約3.3 → 4.25（既定値での測定）。
- 注意: reverse futilityだけの寄与は未分離。置換表共有・null moveは単独では53〜54%だった。詳細は [journal](../../journal/2026-11-07_04_速度改善の見積りと第1段.md)。
