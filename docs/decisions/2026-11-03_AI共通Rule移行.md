# 2026-11-03 ChatGPT・Claude共通Ruleへの移行（雲路）

## 本人指示と確定範囲
- 本人指示：「GitHubの mtk-ctrl/shogi-ai（雲路）と mtk-ctrl/ChatGPT-Codex-（リセット履歴サイト）を、ChatGPT・Claude共通で使えるRuleに整えてください」。
- 雲路はR90に従い、R15とworkflow READMEの作業主体を「作業するAI」とし、Issue作成・GitHub APIが使えない場合の代替を用意する。
- R系Ruleに残る「ChatGPT」「Addness」「Work」を全文検索し、AI固有の依存を削除する。
- 開発ルーターの対局起動に関する重複行を、元の参照先をすべて維持した一行に統合する。
- この変更ではエンジン、評価、学習、対局条件、workflow実装、正式採用を変更しない。

## 判断理由・実装境界
- AIごとにGitHub Issue作成・API・予約実行を利用できるとは限らない。使える場合だけ自動操作し、使えない場合はIssue本文・確認手順を示し、未起動・未検証を明確にする。
- R15では通常対局のIssue受付の権限条件・入力条件・起動手順を維持し、操作主体だけ一般化する。
- R21のタイマーは予約機能を持たないAIにも移行可能な記録手順を加える。自動予約の実施を偽らない。
- ルーターはR90の原則に従い読み先だけを示す。重複していた二経路を、参照文書の和集合を維持して統合する。専用Rule本文の複製は行わない。
- Addnessは2026-11-03から利用保留。R系active Rule本文に「Addness」は存在しなかったため新たな依存を追加しない。
