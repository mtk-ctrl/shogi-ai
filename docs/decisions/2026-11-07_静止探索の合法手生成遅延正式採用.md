# 静止探索の合法手生成の遅延（LazyQTerminal）の正式採用

日付: 2026-11-07
対象: KUMOJI v2.0.24（v2.0.23からの更新）

## オーナーの判断
- AIが、読む手・評価値・ノード数が全局面で一致し1.13〜1.31倍速い第1段の結果を報告した。
- オーナーの原文: 「これは採用していいと思います。でもいくつかを組み合わせてから現行とやらないと、なかなか一つの改善では差が出にくくなっているので、パッケージでの現行モデルとの対局チェックをしたいです。」（2026-11-07）
- 解釈: LazyQTerminalは結果が変わらない高速化として採用する。以後の速度改善（取る手・成る手だけの生成、評価・並べ替え・着手の高速化）は、いくつか組み合わせたパッケージとして現行（v2.0.24）と対局比較し、結果を見て採否を判断する。個別の効果は対局で出にくいため、パッケージ単位で確認する。

## 採用内容
- `SearchEfficiencyMask` の正式既定を24（8＋16）にする。版を v2.0.24 へ進めた。
- 実装: `engine/strategy/iterative_search.h`、`engine/strategy/search_research.h`、`engine/main.cpp`。研究ブランチ `research/speed-qlazy-20261107` をmainへ統合。
- 検証と注意: [見積りと第1段](../../journal/2026-11-07_04_速度改善の見積りと第1段.md)。対局による棋力比較は行っていない（結果が同一のため）。王手でなく合法手が1手もない局面の扱いのみ従来と異なる。
