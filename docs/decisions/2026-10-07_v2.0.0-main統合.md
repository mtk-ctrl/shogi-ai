# KUMOJI v2.0.0をmainへ統合

日付: 2026-10-07

## 背景
Evaluation-v2候補Bは正式採用され、KUMOJI v2.0.0として世代登録されていたが、採用実装と記録が `research/evaluation-v2-challenger` に残り、mainへ統合されていなかった。

その後main側でRules・Workflow・着手記録等の整理が進み、mainと研究branchが分岐したため、「正式Engineはv2.0.0」である事実と「mainを正本とする」運用が矛盾した。

## 決定
- 正式Engine本体はmainに置く。
- KUMOJI v2.0.0の採用済みEngineコード、Evaluation-v2候補B、対応テスト、世代基準、採用記録を現在のmainへ選択統合する。
- 研究branchに残る旧Workflowや整理前文書は丸ごと戻さない。
- 現在のEngine世代はKUMOJI v2.0.0、Android/OEX最新完成版はv1.0.1として分離管理する。
- 正確な実装状態はmain commit SHA、正式比較基準は `benchmarks/baseline_ref.txt` で特定する。
- 以後、正式採用したEngine実装を研究branchだけに残さない。

## 比較基準
