# LMR（後半の静かな手の縮小探索）の正式採用

日付: 2026-11-07
対象: KUMOJI v2.0.22（v2.0.21からの更新）

## オーナーの判断
- AIが400局の比較結果（LMR 230勝1分169敗、57.6%、近似95%区間52.8〜62.5%）と、採用する場合に必要な作業を報告した。
- オーナーの原文: 「現行エンジンの既定にしてください。」（2026-11-07）
- 範囲: LMRのみ。null move（SearchPruneMask bit1）は研究コードとして残し、既定OFFのまま。LMR以外（futility、縮小幅の変更、null move併用）は未採用。

## 採用内容
- `SearchPruneMask` の正式既定を2（LMR）とする。LmrMinDepth=3、LmrAfter=3、LmrReduction=1。
- 版を v2.0.22 に進めた（USIのid name、現行エンジン仕様、postgame解析ツールの識別名）。
- 実装: `engine/strategy/iterative_search.h`、`engine/strategy/search_research.h`（DefaultSearchPruneMask）、`engine/main.cpp`。
- 現行仕様の同期: `docs/現行エンジン仕様.md`（版・設定表・説明）。

## 根拠
- 研究の経緯・測定: [探索深化候補の記録](2026-11-07_探索深化候補_null_move研究.md)。
- 対局run: 42309099128（seed 2026110702）と42310508461（seed 2026110703）。各200局、`go movetime 200`、AdaptiveLongThink・局面知識ON。集計は各shardログの結果行の合算。

## 残る注意
- LMRの設定はパラメータ探索（完走深さ測定）で選んだ。確認対局は同一設定の2回だけで、選択バイアスは小さいが残る。
- 外部ladderでの確認は未実施。
- 採用後に同じ対局を再実行しない（R10）。次の比較基準は採用commitを使う（benchmarks/baseline_ref.txt）。
