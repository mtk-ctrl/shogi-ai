# 2026-10-11 詰将棋約10万問の学習モデル正式採用

## 本人判断
本人の発言（原文）：「まぁ一応正式採用してエンジンに組み込んで組み込んでください」

この発言は、先行した詰将棋10万問学習の有無比較に対する正式採用指示である。正式採用の対象は学習済みモデルによる詰み探索の優先判断と、比較時の成熟度連動・aggressive時間配分を実戦既定へ組み込むことである。自動で重みや学習成果を更新していく制度や、詰み判定そのものを予測で置き換えることまで許したものではない。

## 客観的根拠と不確実性
- やねうら王の公開詰将棋データから抽出した100,000問のうち99,997局面で最大7手の詰み有無を自作探索で学習・評価した（学習実行：Actions run `38095959824`）。
- 自作の16特徴量モデル。教師は雲路自身の7手以内の詰みの証明結果。未学習の24,999局面で正解率63.2585%、予測陽性の適中率72.5764%、詰みの見逃し割合37.6424%（検出率62.3576%）。
- 初期の研究エンジン対現行エンジンでは学習あり53勝・なし44勝・3分。エンジン差が交絡するため単独では効果を測れない。
- 同一バイナリで学習ON/OFFのみ切り替えた100局の厳密比較（Actions run `38108459754`）：**52勝45敗3分、得点率53.5%**、概算95%区間約43.8%～63.2%、違法手0。棋力向上の有意性は未証明。採用は本人の判断であり、統計的証明が得られたという意味ではない。
- 標準比較条件は200ms/手、AdaptiveLongThink ON、同一局面知識、成熟度別詰み探索予算 aggressive、モデルON/OFFのみ変更。
- モデル原本: `engine/models/mate-learning-v2-100k.txt`（SHA-256 `dac182761519a1bebcf93317ebf5214d8a5ae3e65b339e93453fba023a9d0276`）。ビルド時検証して本体に埋め込む。

## 採用上の安全条件
- モデルは詰みの証明ではなく、追加探索を優先する信号としてのみ使用。
- 探索上限・合法手・王手判定・通常αβ探索・局面知識利用を維持。専用go mateは従来通り7手。
- 通常対局の既定は `MateLearning=true`、`MateStageBudget=true`、`MateBudgetProfile=aggressive`、`MateLearningFile=embedded`。
- 序盤成熟度0～33は独立した短手数の詰み補助探索に時間を使用しないが、通常の合法手・詰み判定は除去しない。
- 任意ファイルへの切替は明示設定だけ。読込み失敗で以前のモデルを残して使わない。
- 正式PCエンジン版は v2.0.11。新しいAPKを作成した事実はない。
