# 雲路 KUMOJI v2.0.0 世代基準

## 位置付け

この文書はv2.0.0エンジン世代の現行スナップショットをまとめる設計資料である。運用規範はactive Rules、実装の正本は `main` とする。

v2.0.0は、旧v1系の「Materialを基準に4補正を加える評価」から、複数の局面価値を同じ静的評価ベクトルで統合するEvaluation-v2へ移行した最初の世代である。

最新Android/OEX完成版はv1.0.1のまま。v2.0.0はまずエンジン世代として登録し、AndroidのversionName/versionCode更新・固定署名APK生成・実機確認は通常仕上げ時に別途行う。

## 正式思考条件

- 通常：`go movetime 200`
- AdaptiveLongThink：ON
- 条件該当局面のみ同一探索を最大1秒まで継続
- 1局最大10回
- MateAssist：ON

この条件をv2.0.0の棋力比較基準とする。高速スクリーニングの50～100msやDiagnosisの50/500msは研究条件であり、正式棋力と混同しない。

## 採用根拠

### B対C 直接対決

正式思考条件1,000局：

- B 596勝
- 22分
- C 382勝
- B得点率 60.7%
- 95%区間 約57.7%～63.7%

固定200ms・AdaptiveLongThink OFFの200局ではCが僅差で上回っていたため、時間管理との相互作用が存在する可能性は残る。正式世代の採否は実運用条件の結果を優先した。

## v1.0.1からの世代差

v1.0.1の棋力ロジックはv0.0.19を基準とし、評価はSafety=50 / Pressure=150 / Activity=150 / Danger=200、positional cap=300を中心とした構成だった。

v2.0.0では次が世代差である。

- global positional capを5000へ拡大
- Materialを唯一の支配軸としない
- Influence / Potential / Coordination / Hand Potential / Threatを同じ評価器へ統合
- 多因子の相互作用を大量対局で探索
- 正式条件200ms + AdaptiveLongThinkを含む直接対決で採否
- 外部Material版やねうら王のレベル尺度を世代基準として記録

## 設定ドリフト防止

- C++の `EvaluationParameters` を既定値の正本とする
- USIのdefault表示はその値から生成する
- 旧v1比較は `EvalV2=false` だけでなく旧重み・旧capも明示する
- Workflowに比較用パラメータを複製する場合は「現行」か「歴史的固定条件」かをコメントで明示する
- 外部benchmarkはCPU型番・nodes条件・相手commitを記録する

## 次の比較基準

次のEngine変更は原則としてv2.0.0をChampionにする。

見る順序は、固定局面/単体テスト → controlled match → 正式思考条件の自己対局 → 外部benchmark → Diagnosis。新しい外部AIやKPPT/NNUE系は別尺度として追加し、Material尺度のLv49を消さず並記する。
