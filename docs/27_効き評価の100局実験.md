# 効き評価の100局実験

## 目的と結論

2026-10-06、玉周辺の相互防御、効きの集中、補強のしやすさ、攻守の速度差を着手へ反映する実験版を作り、新評価ON/OFFを同条件100局で比較した。

ONは36勝42敗22分、得点率47%、違法手0であった。今回の配点と実装は正式採用しない。これは効きという概念の不採用ではなく、この候補で改善を示せなかったという判断である。

現行v1.0.1、通常採用版、Book、APK、比較基準は更新しない。候補は `research/influence-100-game` に保存し、デフォルトOFFとする。

## 比較対象

OFFは「新しい効き評価を使わない現行版」であり、既存のAttackMap・Safety・Pressure・Activity・Dangerは残る。盤面の効きを一切考慮しない駒得版との比較ではない。

ONではSafetyとPressureを新しい守備構造・突破圧力に置き換える。旧Safety/Pressureを同時に足さない。Material、Activity、Danger、探索、詰み補助、Bookの内容は共通である。

## パラメータと計算

歩100点のスケールを使用する。先後は同じ関数・同じ係数で計算し、先手分から後手分を引く。

### 有効な効き

- 原則1駒=2単位（1枚）。玉の取り返しは合法性確認が必要なため、静的な枚数には含めない。
- ピンされた駒はピンの射線上に残る効きだけを数える。
- 敵に狙われた重要駒を2枚以上、単独で守る駒は暫定1単位（0.5枚）とする。
- 重要駒は価値500以上、または玉の隣接マスにいる駒とする。
- 枚数だけで飛車対歩の不利な交換を肯定しない。敵の守りがあり、最安攻撃駒が対象駒より高価な場合、その地点の数的優位による突破加点を見送る。

この判定は完全なSEEではない。多段交換、開き王手、全ての取り返しの合法性は通常の合法手探索で判断する。

### 守備構造

玉から距離1にいる自駒が0/1/2/3/4枚以上の有効守備を持つ場合、0/6/16/22/24点を与える。0.5枚分は隣接する配点の間で整数補間する。距離2は50%。距離は縦横の最大距離とする。

片側上限60点。玉から離れた駒へ複数守備のボーナスは付けない。敵に狙われた遠方の駒のリスクは共通の既存Dangerと通常探索で扱う。取らせる意図だけで危険度を免除する機能は設けない。

### 突破圧力

敵玉の距離2以内の敵駒、距離1以内の空きマスを対象にする。敵玉そのものへの王手は通常探索・詰み補助へ任せる。

基礎点 = 12 × max(0,有効攻撃枚数−有効守備枚数)。超過は3枚まで。距離2は基礎点を半減する。

補強到達見積り:

- 1手で新しい守備参加が可能: 係数100%
- 2手で新しい守備参加が可能: 係数150%
- 見つからない・不明: 係数100%（補強不能とは断定しない）

候補は同じ基礎点ごとに平均し、最大の強度階層と次の強度階層の半分を合計する。これは幾何的な戦線分割・全参加駒の排他的な割当ではない。同じ駒による複数マスの加点を抑える集約であり、戦線の分割は今後の研究課題として残す。

1地点上限60点、片側圧力上限100点。最も早い局所脅威を1/2手で推定し、双方の推定がある場合、早い側150%、遅い側50%、同じ100%。どちらか不明なら100%。

### 到達見積りの限界

到達手数は現在盤面上での1駒の静かな経路による「自分の着手回数」の推定である。相手の応手を含む強制手順や、実際に突破するまでの手数ではない。

- 現在の射線、ピン、安い敵駒の効き、行き所のない駒を考慮する。
- 持駒の新規投入を考慮し、二歩・行き所のない駒打ちを除く。
- 王手になる補強候補は見積りから外す。打歩詰め等を静的処理で合法と断定しない。
- 自玉が王手中の補強到達は不明とする。
- 交換、成り、相手応手による射線変更、守備の転用による他地点の損失を全て証明するものではない。

したがって「補強が必ず遅れる」「先に詰ませられる」という保証は与えない。実際の合法応手は通常探索で比較する。この近似の精度は今後、深い自己解析と照合すべきである。

### 着手へ反映する重み

新しい守備構造・突破圧力に共通重み150%を掛ける。新項目の最終上限はそれぞれ片側90/150点。旧Safety/Pressureの倍率をさらに掛けない。Activity/Dangerの現行倍率と、全位置補正±300点の上限は共通で維持する。

USI: `EvalInfluence=false/true`、`EvalInfluenceWeight=150`。設定変更は探索終了後に行い、Experienceの互換署名にも全新係数を含める。material profileでは新評価を無効にする。

## 検証と結果

### 固定・共通局面

- 玉周辺の複数守備、ピン、過負担、駒打ち制約、1/2手補強、不明扱いを確認した。
- 200個の人工盤面で180度回転＋色交換による評価値の厳密な符号反転、内訳一致、上限を確認した。人工盤面検査は合法実戦局面の代用とはしない。
- 元の評価テストの180合法局面・探索oracle、USIの停止/時計/詰み、境界検査、Arenaのtelemetry検査を通過した。
- 新評価のASan/UBSan固定検査は成功。実行環境がptrace下のためLeakSanitizerは利用できず、`detect_leaks=0`で検査した。リーク検査成功とは扱わない。
- 同じプロセスのON/OFF反復切替、入力値検証、material profile分離を確認した。
- 過去の自己対局から重複を除いた100局面をdepth2・静止探索OFF・Book OFFで比較した。
- 新評価で着手12/100局面、静的評価96/100局面が変化した。
- OFFは元コミット `8a750d9...` の実体と全100局面で静的内訳、着手、探索値、nodesが一致した。

### 100局対局

- 同一実行ファイルでA=ON、B=OFF。新評価共通重み150%は開始前に固定した。
- 1手50ms、先後交換50組、初期局面開始、最大200 ply。
- 各組で先手用seed・後手用seedを共通化し、Engineの色だけ交換した。
- Book ON・同一固定内容。MateAssist ON。Experience OFF。
- Intel Xeon Platinum 8573C、公開9 CPU、cgroup 8 CPU、4レーン並列。比較中に配点は変更していない。
- 全着手をpython-shogiでも検証し、各手の盤面事実・評価・PV・depth・nodes等を保存した。

| 指標 | ON | OFF |
|---|---:|---:|
| 勝ち | 36 | 42 |
| 引分 | 22 | 22 |
| 得点率 | 47% | 53% |
| 違法手 | 0 | 0 |
| 総探索nodes | 6,157,058 | 8,079,912 |
| 平均応答時間（Book・通信等を含む） | 41.85ms | 41.79ms |

ONが先手:17勝21敗12分。ONが後手:19勝21敗10分。終局理由は詰み78、手数上限17、千日手5。

先後交換の組ごとの得点から計算した正規近似95%区間は38.9～55.1%。等価の50%も含むため、「弱くなったことを統計的に確定」とは扱わない。改善・採用の証拠は得られなかった。

### 計算コスト

同一100局面でON/OFFを交互に測った5試行では、1評価中央値はOFF約11.25μs、ON約23.63μs、約2.10倍。測定は4レーン対局中に行ったため絶対時間の精密な値にはしない。

共通100局面depth2の平均応答はOFF15.92ms、ON20.08ms。これは静的評価コストと探索される木の変化の両方を含む。

実戦の総nodesはONが約23.8%少ない。ただし各Engineは異なる局面を読むため、この差だけを計算コストの因果効果として断定しない。depth>0の通常探索サンプルで平均完了深さはON約1.22、OFF約1.27だった。評価を重くしたことで50ms内の読みが減った可能性はある。

## 次に検証する仮説

1. 守備構造だけ置換し、Pressureを現行のままにする。
2. 突破圧力だけ置換し、Safetyを現行のままにする。
3. 同じ計算結果を保って、到達見積りの重複計算を減らす。
4. 深い自己探索で、到達・速度の推定が実際の応手に耐えるか確認する。
5. 近接する突破地点の実際の戦線分割、駒の排他的割当、守備転用で失うものを設計する。

今回の100局に合わせて配点を後から調整した結果を、独立した改善証拠とはしない。次候補は新しいseedで評価する。
