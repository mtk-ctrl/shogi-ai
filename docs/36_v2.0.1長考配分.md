# KUMOJI v2.0.1 長考配分

## 変更の理由と範囲

2026-10-08 JST、本人は不安定な局面での長考を認めつつ、枠ごとの所定手数による使用には納得していなかったことと、150手程度までに使い切る希望を回答した。追加の選択式確認では、残った枠は安定局面でも使い切ることを選択した。原文・設問・選択回答・AIの具体化は `docs/decisions/2026-10-07_会話による運用確認.md` の追加確認1に記録する。

本人の時間配分の訂正を実装し、R70の採用ごとの版更新に従いv2.0.1へ進める。Evaluation-v2候補Bの評価値・探索手順・MateAssistは維持し、長考枠の配分だけを変える。v2.0.0のB対C得点率60.7%やMaterial Lv49相当は当時の測定として残す。v2.0.1の棋力向上・同じレベルは今回の動作検証だけでは確定しない。

## 配分

正式運用の正本はR20、配分の実装は `engine/strategy/long_think_budget.h` とする。

- `go movetime 200`、AdaptiveLongThink ON、24手以降の対象手で長考を使う。
- 王手・前回からの評価急落150cp以上・直近の反復深化で150cp以上の評価変動・第一候補の変化・depth2未完了を優先する。回数別の固定開始・期限手数は持たない。
- 150手までの残りの自分の着手機会を、現在の手番も含めて数える。手数が150以下なら `(150 - 現在の手数) / 2 + 1`（整数除算）、150を超えたら0とする。
- 残り着手機会が `10 - 使用回数` 以下になったら、安定した対象手でも延長する。不安定条件があればログの理由はその条件を優先し、残り枠消化だけなら `budget_deadline` とする。
- TT・反復深化・PVを保持した同一探索を合計最大1秒まで継続する。通信余裕を差し引いたdeadlineは通常190ms、延長時は探索開始から990ms。
- 延長を実際に行った手だけを1回として数える。最大10回、`usinewgame` で使用回数と前回評価をリセットする。

150手はSFENの手数（先後合計のply）を指す。残り枠が少なければ、安定局面での消化を始める時期は遅くなる。

| それ以前に使った回数 | 安定局面だけが続く場合の先手 | 安定局面だけが続く場合の後手 |
|---|---|---|
| 0回（残り10回） | 131,133,…,149手 | 132,134,…,150手 |
| 4回（残り6回） | 139,141,…,149手 | 140,142,…,150手 |
| 10回（残り0回） | 追加延長なし | 追加延長なし |

これは計算の例であり、各長考枠に個別の手数を予約する仕組みではない。24手以降に不安定な対象手が続けば、連続する自分の手番で枠を使える。

## 対象外と150手の扱い

Book即決、MateAssistで証明した詰み、探索が詰み評価に到達した場合、合法候補1手、ponder / infinite / nodes指定、200ms以外の要求等は既存の対象条件に従う。固定深度の探索がdeadline前に完了した場合も、消化のためだけに待機・再探索しない。

短い対局や対象外の手が続く対局で、必ず10回使用する保証はない。150手は消化の目標であり、使えなかった枠は失効させず、150手後の次の対象手で消化する。どの場合も最大10回を超えない。
