# Floodgate定跡の長期計画（草案・本人の承認待ち）

作成：2026-11-16。本人の指示「定跡の実装は、しっかり計画を立てた長期の取り組みにする」を受けた草案。承認前は、ここに書いた作業のうち**計画に関わらない既存手順（追加3局面の登録）以外は実行しない**。

## 1. 位置づけ

- 定跡は、新しい仕組みではなく、既存の局面知識（R25）のうち、序盤の連続手順・分岐を整える部分として扱う（2026-10-08に旧Bookは廃止済み）。
- Floodgate専用の層（`tools/floodgate/knowledge-additions.tsv`）で作り、正式採用の163局面は変えない。正式層への昇格は、本人が効果を見て決める。
- 訂正：先に「手順の入れ替わりで定跡が当たらなかった」と書いたが、正しくは、**相手が1手違う（別の局面になる）ため当たらなかった**。局面キーは盤面・持ち駒・手番なので、同じ局面なら手順が違っても当たる。つまり、定跡は**木の広さ**で効果が決まる。

## 2. 現状の事実（2026-11-16）

- 28局＋12局の実戦（40局）で、自分の序盤の局面が他の局と一致する割合は、1手目98%、2手目80%、3〜7手目約50%、8手目30%、9手目以降10〜15%。**深くなるほど木が広がり、到達が急に下がる**。
- 採用中の163局面は、30手以降が153件で、実戦の到達は0回に近い。序盤の局面は11件だけ。
- 追加の3局面は、5手目の7g7fが実戦の3局で即着手された。序盤の評価は互角に戻ったが、3局とも負けた。強い相手には25局0勝。**序盤を直しただけでは勝てず、中盤の評価の見誤りが別に大きい**。定跡の期待値を過大にしない。
- 5分読みは、実戦（15〜60秒）より深さが2〜3深い（深さ10〜14）。深さ12で初めて見える手がある。

## 3. 目的と測り方

目的：**序盤で必要以上に不利にならず、中盤を互角以上で始める。持ち時間を序盤で節約し、定跡を出た最初の手に使う。**

| 指標 | 見方 |
|---|---|
| 定跡到達率 | 1局あたり、定跡で指せた手数（自分の手）。目標：先手・後手とも、自分の8手目まで平均で届く |
| 定跡の出口の質 | 定跡を出た局面を、5分読みし直し、実戦時の評価との差。±100以内 |
| 序盤の急落 | 自分の20手目までに評価が-300以下になった局数 |
| 勝率 | 中位以上の相手に対して。サンプルが少なく、参考値 |

## 4. 設計の柱

1. **範囲は「雲路が実際に通る序盤」を木で持つ**。自分の手は1手（最善）、相手の手は分岐（実戦で観測された手＋雲路自身が読んで有力な手）。先手・後手の両方。
2. **読みは3段階**：S（60秒、全局面の選別）→ L（5分、実戦でよく通る局面・Sで手が違った局面）→ X（30分、評価が深さで揺れる局面・自分の手が分かれる重要局面）。
3. **優先順位は「到達確率 × 不確実性」**。到達確率は実戦ログの通過回数、不確実性は「SとLで手が違う」「深さごとの評価の振れ幅が大きい」。揺れる局面から先に深く読む（飛先突き捨ての9手目のような局面）。
4. **木の上で整合を取る**。葉から根へ評価を戻し（最善手の評価が、その先の相手の最善応手の評価と合うか）、矛盾する手は読み直しに回す。
5. **保存は局面知識TSVに揃える**。列：手順（`source_moves`）、選んだ手、読み時間・深さ・評価、第2候補と評価差、研究時のエンジン版。評価やエンジンが変わったら再読の対象にする（版が古い定跡は失効扱い）。
6. **定跡の出口に時間を使う**。定跡で指した分の持ち時間を節約し、定跡を出た最初の手に上乗せする（Floodgate専用の読み時間の拡張）。
7. **実戦ログの日次ループ**。Floodgateの実行ログから、(a) 定跡の出口の局面、(b) 序盤で評価が急落した局面、(c) 新しい相手の手を、読みの待ち行列へ入れる。
8. **外部データの境界（R50）を守る**。外部AIの評価・PV・手は使わない。相手の実戦手は「どの局面を読むか」を選ぶためだけに使い、正解にしない。他人の棋譜は使わない。**使うのは、雲路自身の読みと、雲路が出た対局の局面だけ**。

## 5. 計算資源

- 5分読みは1台（2コア）で1時間に12局面。非Floodgateの18台（R21）をすべて使うと、**1時間で約216局面、夜間8時間で約1,700局面**。60秒読みなら約10倍。
- 使い方はR21・R30（夜間研究）に従う。Floodgate用の2台には触れない。
- 見積もり：自分の1〜8手目で、実戦の通過が2回以上の局面は先手だけで約30。到達を広げるには、相手の応手の分岐を各2〜3本に絞っても、8手目まででおよそ数百〜千局面。**夜1〜数回で、先手・後手の8手目までが一巡する規模**。

## 6. 段階計画

| 段階 | 内容 | 成果物 | 判定 |
|---|---|---|---|
| P0 基盤（1〜2日） | 読みの工場（Actionsの18台分割、局面の待ち行列、結果TSVの回収）、到達率の計測をFloodgateログに足す | workflowと手順書、到達率の集計 | 18台で動き、結果が回収できる |
| P1 先手（〜1週） | 自分の先手の序盤を8手目まで。相手の分岐は観測された手と、雲路が有力とみる手 | 先手の定跡（追加分） | 到達率・出口の質が目標内 |
| P2 後手（〜2週） | 相手の初手別（2六歩・7六歩・その他）に、自分の後手の序盤を8手目まで | 後手の定跡（追加分） | 同上 |
| P3 拡張・日次ループ（継続） | 10手目→12手目へ深める。揺れる局面にX（30分）。日次の待ち行列を回す | 定跡の増分、日次レポート | 到達率の伸び、急落局数の減少 |
| P4 評価と整理（〜1か月後） | 効果を見て、正式層への昇格を本人が判断。163件と、163件より後の候補（227局面）の扱いを整理 | 昇格案、整理結果 | 本人の判断 |

期間は目安。各段階の終わりに、効果（到達率・急落局数）と、中盤の評価の問題が大きいままかを見て、続けるか、評価側へ人手を回すかを決める。

## 7. リスクと限界

- 木が広がるほど到達率は下がる。9手目以降は、実戦でほとんど同じ局面にならない。**定跡で埋まるのは序盤まで**で、勝率は中盤の評価に左右される。
- 評価の誤りが定跡に焼き込まれる。評価や探索が変わったら、再読が要る。
- 5分読みの手も、深さ14までの判断で、絶対ではない。揺れる局面はXで深く読み、それでも割れるものは採用しない。

## 8. 本人に決めてほしいこと

1. 読みの工場に使う計算資源（夜間に非Floodgateの18台を何時間、毎日使うか）。
2. 先手と後手のどちらから始めるか（おすすめ：先手。通過が多く、すでに飛先突き捨ての材料がある）。
3. 雲路自身の評価以外（深路など）を、定跡の評価の物差しに使うか。**使うなら教師利用の境界（R50、深路F系）の確認が先**。当面は使わない前提。
