# Q14型・局面連動評価の採用時の仕様（KUMOJI v2.0.12）

2026-10-12にオーナーが研究版Q14の正式採用を明示した。本文は当時の実装方式・採用理由を保存した履歴である。2026-10-14にprofile 47へ更新した。現行は `docs/現行エンジン仕様.md` と `docs/39_profile47成熟度連動評価.md` を参照する。

- 成熟度0〜100について、0・50・100の配点3点間を滑らかな3次補間（smoothstep）で接続する。「序盤・中盤・終盤」の境界で急に配点が飛ぶ方式ではない。
- 10評価軸と盤上の駒得倍率・持ち駒の駒得倍率を手番の開始時に決定する。相手の着手時や探索途中には評価重みを変更しない。
- 玉の危険度から20を引いた正の部分（最大80）を玉の安全へ2で割って加算、駒の危険へ3で割って加算する。戦闘度から20を引いた正の部分（最大80）を攻撃圧力へ加算し、3で割った値を脅威へ加算する（整数除算）。
- Q14段階別の値はUSIに設定されたM型基準値に対して比率で適用するため、USIからの個別重み変更の効果も残る。持ち駒の駒得倍率は単独で設定する。G型の駒単価そのものは変更しない。
- 探索、詰み10万問学習モデル、静的評価再利用、局面知識、200ms＋条件付き長考、初手ランダム化を維持する。
