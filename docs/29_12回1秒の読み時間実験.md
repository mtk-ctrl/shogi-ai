# 1局最大12回・1秒長考の100局検証

## 目的

通常50msの現行雲路に、1局につき最大12回だけ1着手の合計上限1秒を与えた場合、現行50msのみより対局成績が改善するかを確認する。

前回の「最大5回・30秒」では探索深度と着手は大きく変わったが、安定した勝率向上は確認できなかった。今回は1回の長考を短くし、使用回数を増やす。

## 条件

- base engine: main `8a750d9f90395b6f9a1cee49547b125c52a6f60b`
- A: 通常50ms + adaptive方式で最大12回、各1秒まで
- B: 現行50msのみ
- 50組100局、各組で先後交換
- OpeningBook ON / MateAssist ON / ExperienceCache OFF
- 400 ply上限
- 4 workers
- 12枠は24 plyから160 plyまでに分散し、序盤に使い切らない
- Book即決、詰み値、合法手1個の局面では使用しない
- 延長候補: 王手中、自己評価150cp以上低下、反復深化内の評価急変/第一候補変更、50msでdepth2未完了
- 50ms probe後に同一局面を再探索する方式であり、探索継続ではない

## 結果

- 違法手: 0
- 平均手数: 137.11 ply
- 実験全体の壁時計: **374.527秒（約6分15秒）**
- 長考使用: 834回、**1局平均8.34回**
- 12回すべて使用: 23局
- 長考後に着手変更: **450回 / 834回（約54.0%）**
- 50ms probe平均depth: **0.817**
- 1秒探索平均depth: **2.436**
- 1秒探索実測: 平均990.34ms、最大991.47ms

先後別:

## 解釈

1秒×最大12回は、今回の100局では現行50msに対して58%を記録し、5回30秒より有望な結果となった。ただし95%区間は50%をわずかに含むため、100局だけで正式採用を確定しない。

特に重要なのは、834回の長考のうち631回（約76%）が「50msではdepth2を完了できなかった」ことを理由に選ばれた点である。現在の雲路では、抽象的な「危険局面」よりも「50msでは探索が足りていない局面」に短い追加時間を与える方が、使い所として有望である可能性がある。

一方、効果は先手65%・後手51%と偏っている。先後交換したpaired comparisonではあるが、追加対局で再現性を確認する価値がある。
