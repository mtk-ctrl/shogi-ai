# 200ms標準＋最大10回の長考検証

## 目的

正式比較の標準を200msへ引き上げたうえで、重要局面だけ最大10回、1秒級まで読むことでさらに強くなるかを確認する。

## 条件

- base engine: main由来 `8a750d9f90395b6f9a1cee49547b125c52a6f60b`
- B: 常時200ms
- A主比較: 常時200ms + adaptiveで最大10回、その手を合計1,000msまで
- A補助比較: 常時200ms + adaptiveで最大10回、その手を合計1,200msまで
- 50組100局、先後交換
- 4 workers
- OpeningBook ON / MateAssist ON / ExperienceCache OFF
- seed `2026100637`
- 違法手0
- adaptiveは200ms probe後に同一局面を再探索する実験方式であり、探索継続ではない

## 主比較: 200ms + 合計1秒×最大10回 vs 200ms

- 長考側: **60勝**
- 200ms側: **37勝**
- 引分: 3
- 長考側得点率: **61.5%**
- pair-normal 95%区間: **51.38%–71.62%**
- 100局壁時計: **824.134秒 = 約13分44秒**
- 長考使用: 736回、**1局平均7.36回**
- 10回すべて使用: 28局
- 長考後に着手変更: 229回 / 736回 = **31.1%**
- 200ms probe平均depth: **1.317**
- 1秒時平均depth: **2.043**
- A平均探索時間/局: 18.81秒
- B平均探索時間/局: 12.55秒

長考理由:
- 200msでdepth2未完了: 425回
- 評価150cp以上低下: 117回
- 王手中: 85回
- 反復深化内の第一候補変更: 57回
- 反復深化内の評価150cp以上変動: 52回

同runの200ms側計算時間から両者200msの壁時計を推定すると約11.1分で、長考追加により**約2.6分（約24%）増**。実測の長考100局自体は15分以内に収まった。

## 補助比較: 200ms + 合計1.2秒×最大10回 vs 200ms

- 59勝40敗1分
- 得点率: **59.5%**
- 95%区間: 49.91%–69.09%
- 壁時計: **813.230秒 = 約13分33秒**
- 長考使用: 709回、1局平均7.09回
- 着手変更: 221回 / 709回 = 31.2%
- probe平均depth: 1.351
- deep平均depth: 2.214

1.2秒へ伸ばしても1秒版を上回らなかった。対局長や発動回数の差があるため壁時計も単純には増えなかった。

## 判断

**200ms + 合計1秒×最大10回は有望。**

100局で61.5%、95%区間下限も50%を上回り、常時200msより強い方向が確認できた。100局壁時計も約13分44秒で、15分程度という運用目標に収まる。

一方、1.2秒へ伸ばす追加価値は確認できない。したがって長考を採用候補にするなら、現時点では**最大10回・合計1秒**がよい。

ただし現runnerは200ms探索をそのまま継続せず、同じ局面から再探索する。実装時は反復深化を継続して残り時間を使える構造にすれば、同じ約1秒予算でもより効率化できる可能性がある。
