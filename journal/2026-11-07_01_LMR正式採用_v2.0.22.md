# 2026-11-07 LMRを正式採用（v2.0.22）

## 起点
200ms時の平均完走深さが約2.9で、枝刈り・探索縮小が未実装だったため、探索深化を最優先として自作の枝刈りを一つずつ試した。

## 結果
- null move（自作 `Position::pass_position`）: 完走深さ2.917→3.188。200局 101勝3分96敗（51.2%）。効果を示せず、既定OFFの研究コードとして保持。
- LMR: 完走深さ約3.15、ノード数約17%減。200局 111勝1分88敗、別seed200局 119勝0分81敗、合算400局 57.6%（近似95%区間52.8〜62.5%）。
- null moveとLMRの併用は深さ3.292（測定のみ。対局未実施）。

## 採用
オーナーが2026-11-07に「現行エンジンの既定にしてください。」と指示。`SearchPruneMask=2` を既定にし、版をv2.0.22へ更新した。詳細は [採用記録](../docs/decisions/2026-11-07_LMR正式採用.md)。

## 実装上の注意・教訓
- やねうら王のnull move処理はrules-only patchに含まれないため、自前でSFENの手番反転による局面を作った（R50の範囲）。
- GitHub Actionsのartifact取得がプロキシで拒否されたため、shardログの結果行を合算した。aggregate.jsonは未確認。
