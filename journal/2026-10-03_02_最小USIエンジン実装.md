# 2026-10-03 最小USIエンジン実装

## 目的

自作将棋AIの実装を開始し、ShogiDroid2へ接続する前段階として、USIの最低限の応答ができるエンジンを作る。

## 実装内容

`engine/main.cpp` に最小USIエンジン v0.0.1 を作成した。

対応するコマンドは以下。

- `usi` → エンジン名等を返して `usiok`
- `isready` → `readyok`
- `usinewgame` → 現時点では何もしない
- `position ...` → 現時点では受信のみ
- `go` → 固定で `bestmove 7g7f`
- `quit` → 終了

現段階では盤面を理解せず、合法手生成も行わない。目的はUSI接続経路の確認だけである。

## テスト

ローカル環境でC++17としてコンパイルし、以下の入力を与えた。

```text
usi
isready
position startpos
go
quit
```

出力：

```text
id name shogi-ai v0.0.1
id author mtk-ctrl + ChatGPT
usiok
readyok
bestmove 7g7f
```

最小のUSI応答が正常に動作することを確認した。

`tests/test_usi.py` も追加し、今後同じ応答を自動確認できるようにした。

## 現在できること

- USIの初期応答
- 準備完了応答
- `go` に対して固定の7六歩を返す

## まだできないこと
