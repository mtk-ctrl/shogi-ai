# 雲路 KUMOJI v1.0.1 完成版

## 位置付け

2026-10-05、これまで `shogi-ai` として開発してきた自作将棋AIに **雲路（くもじ / KUMOJI）** という名前を付け、ShogiDroid2で利用できる最初の完成版を **v1.0.1** とする。

リポジトリ名 `mtk-ctrl/shogi-ai` は開発史と外部参照の継続性のため変更しない。AndroidのApplication ID `com.mtkctrl.shogiai`、native engine filename `libshogiai.so`、固定開発署名も、既存APKからの更新互換性を守るため維持する。

## 棋力ロジックの基準

v1.0.1の戦略・評価・探索の基準は正式採用版 **v0.0.19** である。

直前にv0.0.20候補として検証したKiller heuristic、History heuristic、PVS、Aspiration windowは、固定深度で一部改善があっても50ms実戦で再現性のある棋力向上を確認できなかったため不採用であり、v1.0.1には含めない。

したがって今回のv1.0.1化は、強さの比較条件を汚す新戦略導入ではなく、次を目的とした完成版化である。

- 製品名を「雲路 KUMOJI」に統一
- Android / OEXを現行エンジンへ追随
- ShogiDroid2向けAPKを生成可能にする
- 自前Opening Bookをスタンドアロン実行時にも利用可能にする
- 完成版用CIを強化する
- 羅針盤に名称と由来を反映する

## 名前

「雲路」は、雲の中の道、空に通う道を表す古い日本語から取った。

既に敷かれた道をなぞるのではなく、まだ道に見えないところから自分で通れる筋を見つける、という意味をこのプロジェクトの思想に重ねる。

外部AIは先生ではなく物差しとし、Engine / Experienceを自分たちで育て、まず現行版との自己対局で進化を確かめ、その後に外部BenchmarkとDiagnosisで強さと理由を検証する。

## Android / OEX

- 製品表示名：`雲路 KUMOJI`
- OEX表示名：`雲路 KUMOJI v1.0.1`
- Android versionName：`1.0.1`
- Android versionCode：`10101`

アプリ内のUSI接続テスト画面はversionNameをBuildConfigから表示し、今後のAndroid版更新で表示だけが古くならないようにした。

## Opening Bookのスタンドアロン化

v0.0.19では自前Opening Bookを標準ONとしているが、OEXホストは通常、実行エンジンだけを取り出して起動するため、リポジトリ直下の `shogi-ai-book.tsv` を実行時に参照できない可能性がある。

v1.0.1ではビルド時に現在の `shogi-ai-book.tsv` をC++ヘッダへ埋め込み、標準ファイルが実行場所に存在しない場合だけ内蔵版へフォールバックする。

- PC等で外部 `shogi-ai-book.tsv` がある場合：従来どおり外部ファイルを優先
- Android/OEX等で標準ファイルがない場合：同じ内容の内蔵Bookを利用
- `OpeningBookFile` で独自パスを指定した場合：内蔵Bookへ勝手に置き換えず、従来どおり指定ファイルの成否を尊重

これにより、研究時のBook差替え能力を残したまま、APK単体でも現行のBookを失わない。

## 完成版CI

通常の戦略pushは従来どおりQuick Strategy CIを使う。

`android/VERSION` の変更は完成版を作る明示的な合図とし、Android OEX APK workflowを自動起動する。完成版では次をまとめて確認する。

- ルール層・独立差分検証
- strategy / search / quiescence
- 詰み探索 / MateAssist
- Opening Bookと内蔵Bookフォールバック
- move ordering
- evaluation / fixture / USI
- Experience Cache
- Sanitizer
- ARM64 NDKビルド
- Android APK生成
- 固定開発署名の証明書一致

APK artifact名は `KUMOJI-v1.0.1-fixed-debug.apk` とする。
