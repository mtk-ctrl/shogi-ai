# 雲路 KUMOJI v2.0.0 新世代登録

## 結論

2026-10-07、Evaluation-v2候補Bを正式採用し、雲路のエンジン世代を **KUMOJI v2.0.0** として登録する。

これはv1.0.1のパッチ更新ではなく、局面評価の設計思想を更新した世代変更である。

## 採用値

- EvalV2=true
- EvalMaterialWeight=100
- EvalSafety=500
- EvalPressure=474
- EvalActivity=150
- EvalDanger=200
- EvalInfluence=19
- EvalPotential=25
- EvalCoordination=50
- EvalHandPotential=60
- EvalThreat=0
- EvalPositionalCap=5000

## 採用までの検証

広域探索では単因子の主効果だけでなく、Material×Safety、Safety×Threat等の相互作用を確認した。625設定の完全全探索からA/B/C/Dの4候補を残し、4候補の直接対決、現行v1との比較、正式思考条件でのB/C再戦、外部やねうら王Material版で絞り込んだ。

正式思考条件のB対C 1,000局は、B 596勝22分382敗、B得点率60.7%。固定200msだけの小標本ではCが僅差で上回ったが、正式運用条件ではBが明確に上回った。

外部Material版では低～中レベルでCがやや良い区間もあったが、Lv60ではB 19.0%に対してC 6.0%。直接対決と強敵側での崩れにくさを重視しBを採用した。

- Lv49: 45勝4分51敗、47.0%
- Lv50: 43勝0分57敗、43.0%
- Lv51: 39.0%
- Lv52: 30.5%
- Lv53: 34.0%
- Lv54: 23.5%
- Lv55: 22.0%
- Lv56: 18.5%

したがって、v2.0.0のMaterial版やねうら王基準は **Lv49相当、互角帯Lv48～49** と記録する。Lv50はまだ越えていない。

## 世代登録時の整理

- `EvaluationParameters` の既定値をBへ変更
- USI defaultを同じ値から生成し、表示と実値を一元化
- USIエンジン名を `KUMOJI v2.0.0` へ更新
- 旧v1 benchmarkは旧重み・旧capを明示固定
- 旧eval-balance workflowはEvalV2=falseを明示
- Nightly Researchのweight-up候補をB基準へ更新
- README / roadmap / 評価v2設計 / 外部benchmark文書 / CHANGELOGをv2.0.0基準へ整理
- `docs/33_v2.0.0世代基準.md` を現行世代の短い正本として追加

## Androidとの境界

この登録は**エンジン世代の確定**である。

Android/OEXの最新完成版はv1.0.1のまま保持する。`android/VERSION`、versionCode、OEX表示名、APK artifactはこの時点では変更しない。v2.0.0 Android通常仕上げを行うときに、CI・固定署名・実機確認までまとめて更新する。

## 次世代への基準

以後の評価・探索・戦略変更は、特別な理由がない限りv2.0.0をChampionとして比較する。Material Lv49は残し、KPPT/NNUE等の異なる外部尺度は別系列として並記する。
