# v0.0.19 通常goへの攻守詰み補助

2026-10-05、v0.0.18で十分に軽くした自作詰み探索を、通常対局の`go`へ初めて組み込んだ。今回の目的は「こちらが短い詰みを見つける」だけではなく、候補手を指した直後に相手から短い強制詰みを受ける手を避けることである。

## 実装範囲

通常の時間制限付き`go`では、通常探索の前に`MateAssist`を実行する。

攻撃側では、現在のroot候補の範囲内で1手詰め・3手詰めを専用AND/OR探索で確認する。強制詰みを証明した場合は、その詰み手を直ちに`bestmove`候補とする。

防御側では、root候補を1手ずつ仮に指した局面から、今度は相手側を攻め方として同じ1手・3手詰み探索を実行する。相手の強制詰みを証明できた候補だけを通常探索のroot候補から除外する。

重要なのは、時間切れや探索範囲内で証明できなかった候補を「安全」と断定しない一方、危険手としても除外しないことである。短い予算で未証明だった手を誤って消さない安全側の実装とした。また全候補が強制詰みを受ける場合は元の候補集合へ戻し、通常探索に最善の粘りを選ばせる。

`searchmoves`が指定された場合は、攻撃側詰み探索もそのroot候補だけを対象にする。

## 時間予算

通常探索50msを大きく侵食しないよう、詰み補助の総予算は通常思考予算のおおむね10%、最大5msとする。現在の50ms比較条件では内部の通常探索予算が約45msであるため、MateAssistは4ms上限となる。

その短い予算を攻撃側だけで使い切らないよう、攻撃側には概ね3分の1を先に与え、残りを防御側へ確保する。攻撃側が時間切れでも、防御側の確認は残り予算で続行する。

固定深度、nodes指定、ponder、infiniteではMateAssistを挿入せず、従来の探索意味を維持する。USI option `MateAssist`でON/OFFでき、標準はONとする。

## 軽量化

防御側はroot候補ごとに合法手を再生成しない。v0.0.18で導入したrules層のopaqueな`GeneratedMove`をrootで一度だけ生成し、USI文字列とtokenを対応付けた後は直接着手・undoする。やねうら王の`Move`型はstrategy層へ公開しない。

## 正しさの固定テスト

`tests/mate_assist_test.cpp`を追加した。

- 既存の実戦由来5手詰めの途中局面から、通常go補助が厳密な3手詰めを発見する
- 人工局面で、ある候補手だけが相手の1手詰めを許すことを確認し、その候補だけを除外する
- 全候補が詰まされる場合は候補集合を空にせず元へ戻す
- 攻撃・防御いずれのprobe後もroot局面を復元する

既存の詰み探索回帰、GeneratedMove回帰、USI回帰も通過した。

## 50ms自己対局

同一バイナリで`MateAssist=true`と`false`だけを変え、Experience Cacheは両側OFF、1手50msで比較した。先後はarenaの通常ルールで交互にした。

### run 1 — seed 20261005

- MateAssist ON: 45勝
- OFF: 54勝
- 引分: 1
- ON得点率: 45.5%
- 違法手: 0
- ONのMateAssist実測平均時間: 約0.768ms/回
- 強制詰み即決: 79回
- 相手の3手以内詰みを許すと証明したroot候補: 合計28,640手

### run 2 — seed 20261006

- MateAssist ON: 64勝
- OFF: 31勝
- 引分: 5
- ON得点率: 66.5%
- 違法手: 0
- ONのMateAssist実測平均時間: 約1.270ms/回
- 強制詰み即決: 104回
- 相手の3手以内詰みを許すと証明したroot候補: 合計13,154手

### 200局合計

- MateAssist ON: **109勝**
- OFF: **85勝**
- 引分: **6**
- ON得点率: **56.0%**
- 違法手: **0**
- MateAssist呼出し: 13,218回
- MateAssist総時間: 13,714ms、加重平均約**1.04ms/回**
- 強制詰み即決: **183回**
- 防御側で相手の3手以内詰みを許すと証明した候補: **41,794手**

2回の100局結果は45.5%と66.5%で振れが大きく、200局56.0%だけから強さの増加量を精密に推定することはしない。ただし合計では負け越さず、通常50msの中で実コストは平均約1ms、固定テストで攻撃・防御双方の意図した動作を確認したため、v0.0.19として採用する。

## 現時点の範囲

通常`go`へ常時入れるのは1手・3手までである。専用`go mate`は従来どおり最大7手まで読む。

5手・7手を通常対局の毎手に無条件で追加することはまだしない。次は詰みの可能性が高い終盤・王手周辺などの条件を設け、攻撃側だけでなく防御側にも同じ考え方で5手以上を試す。その際も総時間予算内で比較し、50ms自己対局で採否を決める。

Android APK・実機確認は今回の対象外である。
