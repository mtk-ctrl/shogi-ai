# 2026-11-14 コア数に合わせたスレッド数の自動調整（v2.0.31）

## 目的
2スレッドの読みは、コアが2つ以上ある環境（GitHub Actions）を前提にしている。コアが1つしかない端末・サーバーでは、2本が1つのコアを分け合って読みが浅くなる。オーナー指示（2026-11-14「コア数に適した思考ができるように改善して実装してほしい」）で、環境に合わせて自動で切り替えるようにした。

## 実装
- `engine/strategy/cpu_budget.h`（新規）: 使えるコア数 = OSの報告（hardware_concurrency）、プロセスに割り当てられたコア（sched_getaffinity）、コンテナのCPU上限（cgroupのcpu.max / cfs_quota）の最小。分からなければ0（抑えない）。
- `engine/main.cpp`: `AutoThreads`（既定 true）を追加。実際のスレッド数 = min(SearchThreads, コア数)。`isready` で `info string search_threads requested N usable_cores C auto true using M` を出す。版名 v2.0.31。

## 確認（サンドボックス、2コア）
| 条件 | 表示 |
|---|---|
| 既定（2コア） | requested 2 / usable_cores 2 / using 2 |
| 1コアに制限（taskset -c 0） | requested 2 / usable_cores 1 / using 1 |
| 1コア・AutoThreads=false | using 2（従来どおり） |
| SearchThreads=1 | using 1 |

- 2コア・既定で固定深さ5の24局面: v2.0.30と手・評価値が全一致（24/24）。
- 1コアに制限・200ms・24局面の平均完走深さ: v2.0.30（2スレッドのまま）3.92 / 3.96、v2.0.31（自動で1スレッド）4.42 / 4.33。
