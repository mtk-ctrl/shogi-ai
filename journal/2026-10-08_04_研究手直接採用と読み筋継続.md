# 2026-10-08 研究手直接採用と読み筋継続（KUMOJI v2.0.4）

## 採用判断
本人原文：「まずは研究手に当てはまる場合は読み筋丸ごと当てはまるうちは無条件採用を採用します。正式実装してください」

## 動作
- 既に採用した長考研究局面と一致したら、研究手を通常の200ms探索で選び直さず直接選択する。
- 読み筋に記録された相手の応手を含む局面・到達履歴が一致すれば、次の自分の研究手も直接選択する。外れたら通常探索へ戻す。
- 終局判定、反復履歴の安全側停止、着手合法性、探索対象の制限、知識無効時の通常動作を維持する。今回の探索で読み直したかのように過去の評価・深さを出力しない。
- 研究の識別番号・読み筋内の手順を対局時に出力し、着手記録へ研究出所を保持する。旧Book / Experience概念は復活させない。

## 元研究と採用範囲
GitHub Actions run 37671846680、アーティファクト `v2-position-knowledge-research-37671846680` の原研究に残る読み筋を使用。既に採用済みだった60秒研究53局面の指し手と照合し、読み筋全手の合法性を検査した。長さは4～8手で、相違のある7局面は従来どおり除外。初回適用は盤面だけでなく、元研究局面までの着手履歴も一致するときに限定し、別手順で到達した同一盤面へ研究を無条件流用しない。読み筋の継続時も各後続局面・履歴を照合する。改めて研究や新規候補の自動昇格を行っていない。

復元は既存の `Position Knowledge Refresh` を拡張した。run 37757508705で成功を確認し、53件すべて研究手直接採用モードとなった。研究データのmanifestは`position-knowledge-v1.manifest.json`が正本。
