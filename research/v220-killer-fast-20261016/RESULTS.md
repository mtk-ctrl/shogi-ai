# v2.0.20：成功手優先処理の軽量化研究結果

正式基準は `a17980ebd65c960a3c486989e348f5853a098b7d`（KUMOJI v2.0.20）。次の強化を実装・測定したが、**採用候補へ進める事前基準は未達、正式エンジンへは反映しない**。

## 試作と検証

1. 最大2手の優先候補だけを静かな候補の中で安定移動し、静かな候補全体の配列作成・安定ソートを省く。駒取り・成りの位置と、残る手の相対順を維持。
2. さらに、優先候補が実際の一覧に見つかるまで盤面コピーを遅延する。履歴方式ON時は従来の並べ替えへ戻る。

両案は別々の研究設定（SearchOrderingFast / SearchOrderingLazySnapshot、双方既定false）。PVS・killerの正式既定3、評価・合法候補・深さ・時間配分・2スレッド・先読み・知識は変更しない。

独立した安定ソート参照との2万パターンで順番と一致回数が一致。初案600ケース、追加案1200ケース（15局面、1/2スレッド、静止探索ON/OFF、mask 0/1/2/3/7、両設定ON/OFF）で、手・評価・PV・深さ・節点数・打切り・既存統計が正式バイナリと完全一致。追加案の対象4205回のうち盤面コピーは2089回に減った。時間制御、長考10回上限、停止、isready、ponderhit、quit/EOF、外部コード境界の検査も通過。比較のPV・候補列はRAM内だけで扱い、成果物へ保存しない。

## 計測と判断

24局面×3回、同時に1エンジンだけ動かし順番を入れ替えた対応比較。固定深さ2と200msを分離。2スレッド・知識ON・RiskVerify ON。診断のため初手ランダム・詰み補助・長考・先読みはOFF。

事前に、固定深さの全結果一致、速度中央値と全時間比が双方1.02倍超、200msの深さ合計が基準以上であることを対局移行条件にした。結果を見て閾値を緩和しない。

初案は中央値1.0536倍、全時間比1.0505倍だったが、200ms深さ合計205対206で未達（pilot）。追加案と併せた再計測は以下。

| 条件 | 固定深さ速度中央値 | 全時間比 | 200ms深さ合計 | 深く/浅くなった試行 |
|---|---:|---:|---:|---:|
| official_v2020 | 1.0000倍 | 1.0000倍 | 214 | 0 / 0 |
| control | 0.9792倍 | 0.9852倍 | 216 | 2 / 0 |
| fast | 1.0067倍 | 0.9925倍 | 216 | 2 / 0 |
| lazy | 1.0229倍 | 1.0037倍 | 216 | 2 / 0 |

倍率は正式基準の時間÷各条件の時間。追加案は中央値約2.3%改善、総時間は約0.4%改善で基準未達。候補OFFにも約1.5%の総時間差があり、小さい差を安定した高速化と解釈しない。コピーを減らせたという内部事実と、全体の処理時間・到達深さ・棋力の改善は別である。

**どちらも200局の実戦比較は起動しない。** 正確性は保てたが、実装の複雑さに見合う安定した速度利得を今回の基準で確認できなかった。勝率を測っておらず、棋力が上がったとは報告しない。研究ソース・計画・計測・検証結果をこのブランチに保存する。
