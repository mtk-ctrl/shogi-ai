# 合格した研究親からの次世代学習

独立200局が事前の強化条件を満たした場合だけ、同じ制御処理が保存する次世代100局を入力にする。
元の500局や比較200局を新たな学習100局として数えない。

- 親の固定commit・モデルSHA・有効化設定と、両側の実行設定・実バイナリを照合する。
- 保存した原本を再取得し、容量・SHA・Release API digestを照合する。全着手・終局理由を再検証する。
- 学習手順、64特徴、棋譜70/15/15分割、各局8局面、正則化候補と300回の学習は最初の試行と同じ。
- 学習元として許すBのバイナリは、今回の親の実バイナリSHAを明示する。未知の版を黙って混ぜない。
- 新しい重みは次の研究候補として保存する。この追加学習だけでは親を更新せず、同じ比較・独立確認を次の候補にも必要とする。

この工程は新しい学習入力の継承を確かめるもので、再学習候補の棋力向上を示すものではない。
