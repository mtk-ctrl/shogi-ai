# 自己対局から探索順を学ぶ試行

目的は、着手記録から汎用の読む順番を学び、200msの実対局で研究用の親を改善すること。
正式採用、既定値、版番号、採用済み局面知識163件、比較基準は変更しない。

## 固定する条件

- 入力は保存済みの自作エンジン500局（match 38946175603 / 38946985753 / 38947702135 / 38948701892）。外部AIの着手は使わない。
- 全局を再生し合法性を確認する。学習対象は同一の現行側Bが実際に選び、探索評価と深さ2以上を記録した手。勝者の全着手を正解とみなさない。
- 同一棋譜をまとめ、棋譜ハッシュで学習70%・選択15%・最終予測確認15%へ固定分割する。分割をまたぐ同一局面を除外する。各局最大8局面を履歴ハッシュで先に選ぶ。
- 合法手の特徴量は自作コードで抽出。線形の着手選択モデルを交差エントロピーで学び、読む順番にのみ加算する。着手の直接指定・合法手の除去・評価値の上書きはしない。
- 正則化候補は0.001 / 0.01 / 0.1、学習反復300回、選択用データの損失が最小のモデルを選ぶ。最終予測確認データを選択に使わない。
- 実対局の候補は加算量50% / 100% / 200%の3個。通常200ms、長考ON、先読みON、2スレッド、同じ採用知識と通常既定値を使う。
- 各候補100局の探索比較を行い、違法手0・実利用あり・得点率50%以上の中から得点率が最大の1個を選ぶ。同率なら小さい加算量を優先。
- 比較seedは50%が2031101801、100%が2032101801、200%が2033101801、独立確認が2036101801、次世代が2041101801。各laneは標準runnerどおり10万ずつずらす。
- 選んだ1個だけ、別seedで200局の確認比較を行う。引分半点の得点率と、同一棋譜をまとめた得点率の95%下限が共に50%を超えることを研究親更新の条件にする。
- 無効化時の固定深度一致、全合法手の保存、先後反転特徴一致、詰み等12対照、探索速度を検査。実時間・探索量の増減も結果に記録する。
- 合格した研究候補を次世代の研究親へ引き継ぎ、同じ親同士の新しい自己対局を100局保存・再分析する。次世代の学習入力には元棋譜の分割群を引き継ぐ。
- 不合格なら親は維持する。理由を調べ、新しい仮説の計画を結果閲覧後の別試行として固定する。閾値の緩和や確認対局の繰り返しで合格させない。

## 保存境界

永続保存は実着手、入力の同一性、分割、学習モデル、集計値、検査結果と研究親の継承記録。
全合法候補の特徴行列や未着手の候補一覧は一時作業に限り、継続Releaseへ保存しない。
勝率や予測一致率だけで、探索が深くなった・実力が上がったとは報告しない。
