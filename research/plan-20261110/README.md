# 強化計画案のための事前測定（2026-11-10）

計画と結果は `journal/2026-11-10_01_強化計画案_頭打ちの診断と事前測定.md`。

- `probe.py`: USIでエンジンを動かす小さな道具。`python3 probe.py gen` で自己対局3局（1手40ms）を作る。エンジンは環境変数 `KUMOJI_ENGINE`（既定 `build/kumoji`）。
- `measure.py`: 各局面を200msと1秒で探索し、深さ・節点の内訳・手の変化を記録する。
- `games.json`: 測定に使った自己対局3局の着手列（v2.0.29同士。外部AIは不使用）。
- `probe_switches.patch`: 診断用の一時的な切替（環境変数）。置換表の盤面キー、静止探索の深さ上限、静止探索で読む手の粗い絞り込み。mainには入れていない。研究用で、採用候補の実装ではない。
