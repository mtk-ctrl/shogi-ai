# 探索効率化・5分野の統合研究（v2.0.16固定基準）

この研究ブランチは候補コードであり、正式採用・版番号更新ではない。mainの既定23/8/6、profile47、局面知識163件、詰み学習、200msと条件付き最大1秒を維持する。対象はすべて自作探索・評価のみ（外部エンジンの探索実装は使用しない）。

## 今回の実装対象
1. 合法手探索の索引化：LegalBatchに文字列表現→生成済み合法手トークン番号の索引を保持して、着手時の線形探索を減らす。研究USI `SearchNextMask` bit 1（ON=1）。文字列そのものを完全廃止する抜本変更ではない。
2. 読み筋の軽量化：各探索節点の可変長vectorを廃し、各深さの固定長配列に読み筋を保持する（研究ブランチ全設定に適用）。評価式・探索順は維持。反復探索終了後、ルートのPVだけ文字列へ戻す。
3. 候補手の並べ替え：`SearchNextMask` bit 2は暫定の上位12手詳細評価、bit 4は上位6手詳細評価（競合時は4を優先）。低コストの駒取り・成り・退避概算で先に候補を並べ、該当数のみ既存の重い戦術解析を実行する。**全合法手を探索**し、枝刈り条件は変更しないが、選択手・評価値・勝率は変化し得る。現行の全手詳細評価は mask 0 のまま。
4. 攻撃情報の高速化：`SearchReuseMask` bit 8で、飛角香等の射線・全駒の利き構築の升移動を事前計算済みの表から参照。静的評価と並べ替えの攻撃マップに適用。既定6は維持。これは**差分更新や攻撃マップ自体のキャッシュではない**ため、速度の利益は未確定。
5. 置換表の反復間再利用：`SearchNextMask` bit 8で深さ更新ごとの置換表世代更新を省く。探索開始時の世代更新は維持し、ルートや評価パラメータを越えて再利用しない。保存深さ一致と履歴を含むkeyの検査を維持。反復またぎの有効性と千日手条件を回帰・対局で検証する。

## 検証順序
- 既定（next0/reuse6）のC++/USI/探索・詰み・PV合法・盤面復元回帰。
- 同一局面固定深さで、next1、next2、next4、next8、reuse14と複合設定について合法手・評価・PV・節点・応答時間を測る。探索順変更2/4は指し手一致を強制せず、score変動理由を分析する。
- 速度上位の設定だけ200ms・追加長考ON・採用知識163件の先後均等比較。候補の優位性がなければ正式mainには反映しない。
- 速度中央値だけでなく合計時間比、200ms到達深さ、節点数、違法手、停止/タイムアウト、継続対局も評価する。

## 実験境界
- 新機能の基本既定は `SearchNextMask=0`、`SearchReuseMask=6`。PV固定配列のみ研究版常時ON。
- Mask 2/4は対立する別案であるため「同時採用」はしない。
- 現在は検証前の研究実装。数値成果、棋力優位、採否は未判定。
