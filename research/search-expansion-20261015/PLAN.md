# 探索効率化の多方式比較（2026-10-15）

## 対象と目的
本人指示「探索効率化をもっともっと強化」「色んな方法」「別のチャットで試していたバージョンをさらに強化」に基づく研究。正式mainはKUMOJI v2.0.13 / profile47（73884f6）を維持。
基礎候補はPR259の7ab3dab9b909503d340fb1f374da09f8d0e2e209。別チャットの同じ変更の100局は51勝3分46敗（run38546410593）、PR259の別標本は53勝3分44敗（run38552982934）。独立した測定として区別し、今回の結果へ混ぜない。

## 5方式と照合条件
| bit | 方法 | 保つ条件 |
|---|---|---|
| 1 | 生成済み合法手の不透明トークンをそのまま着手 | ply別に盤面・持ち駒・手番のkeyを照合。ルール層のsource key検査を維持 |
| 2 | 終局判定と着手候補で同じ合法手一覧を共用 | 千日手は毎回判定、合法手0なら詰み/合法手なし負けの従来分類 |
| 4 | 通常探索の並べ替え結果を再利用 | 同じgo、局面keyと元の合法手一覧が一致。各種hintは再利用後に毎回適用 |
| 8 | 静止探索の得点・境界を再利用 | 同じgo、rootの向き、全順序履歴、plyとqplyを固定。盤面だけの得点共有を禁止 |
| 16 | 前反復の有力手をdepth2から先に読む | 評価や候補省略は変更せず、rootの厳密な同点比較を維持 |

SearchResearchMask=0はPR259の探索経路。1/2/4/8/16の単独、3/7/15/23/31の組合せ、計11設定を同一バイナリで比較。正式採用と正式版名更新は行わない。

## 検証と選定
1. 通常探索・静止探索の独立全幅oracle、詰み・千日手・node/time/stop・USI・局面知識・詰み学習の既存回帰を通す。
2. 保存済み合法な棋譜から序盤～終盤の局面を事前固定。固定深さで選択手・得点・完了深さ・PV合法性を照合。cache/hintでは途中PVや節点数の全一致を要求しない。生成/判定/並べ替え再利用の保存案は結果の同一性を基本とする。
3. mate専用補助・追加長考・初手ランダムを無効化した200ms診断で到達深さと探索量を分けて観測。採用済み知識はON。正式対局条件とは区別。
4. 初期スクリーニングはローカル回帰compileと一部時間が重なるため速度の確定値にはしない。有望設定をcompile終了後に対応順を入れ替えて再測する。
5. 不一致がなく速度/到達深さが有望な最大2案をPR259候補に正式条件各100局で比較。最大10runner、同seed/先後均衡・200ms＋長考ON・同一知識163。5lane×20局ずつを基本とし、他run使用量を確認して調整。
6. 勝敗と探索量を見て1案を選び、正式mainへ独立100局。これは候補選定用とは別標本とする。改善を断定せず区間・違法・時間・知識・保存を確認して報告。

研究ソース・測定要約は本branch、実対局の全着手は既存engine-matchの90日artifact。大量raw棋譜をソースへcommitしない。最終結果を確認するまでR21に従い追跡し、必要なら確認タスク1本を更新する。採否はR10に従い本人判断。
