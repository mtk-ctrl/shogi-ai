# 自己対局の勝敗から既存評価配点を学ぶ試行

読む順番の試行とは別仮説。実着手の予測だけでは、親にもある評価の誤りを修正できないため、検証済みの自己対局結果を既存評価の配点へ結び付ける。
読む順番の試行が強化を確認できた場合は、この追加比較を起動しない。

- 入力は同じ保存済み自作500局。現行側Bの局面だけを使い、未採用側Aの着手を正解にしない。外部AIは使わない。
- 全局の合法性・終局理由を再検証する。打切りは勝敗ラベルに使わない。棋譜全体のハッシュで70/15/15分割、同一棋譜をまとめ、分割をまたぐ同一局面を除く。
- 16手以降、終局の12手前までから各局最大8局面を履歴ハッシュで先に選ぶ。評価の絶対値800cp以下・clampなしの局面だけを使う。選択に勝敗は使わない。
- 素材点・成熟度・手駒倍率は固定し、現行の9配点だけを親の±25%以内で学習する。手番の符号や切片で勝者・B側を当てる特徴は入れない。
- 黒から見た評価を600cpの温度で勝敗確率へ変換し、1局の合計重みを等しくする。L2は0.001 / 0.01 / 0.1、Adam500回。選択用データの交差エントロピーで1モデルを選び、最終予測確認用データを選択に使わない。
- 選択用損失が親から0.002以上改善した場合だけ候補を作る。予測改善を棋力の証拠にはしない。
- 学習差分の25% / 50% / 100%を3候補とし、それぞれ通常200ms・長考ON・先読みON・2スレッド・同一知識163件で100局比較する。seedは2051101801 / 2052101801 / 2053101801。
- 違法手0、同一条件確認済み、得点率50%以上の中で最大の1個を選ぶ。同率なら小さい変更。事前に基本対照12件・速度16局面を検査する。
- 選んだ1個だけ別seed2056101801で1000局の独立確認を行う。得点率の95%下限が全局・既存棋譜と内部重複を除いた集計の両方で50%を超えたら研究親を更新する。小さな改善も測るため確認局数を先に1000と固定し、結果を見て追加しない。
- 合格した親同士の300局（seed2061101801）を新規保存・再分析し、その入力から次のモデル提案まで実行する（確認用局面を最低50件ずつ確保できる局数を先に取る）。親の9配点を引き継いだことを実行メタデータで確認する。
- 正式main Engine、版番号、既定値、基準・知識は変えない。研究候補の正式採用は本人の判断に従う。不合格はそのまま保存し、閾値を変更しない。
- 永続保存は原棋譜の同一性、分割・選んだ実局面、学習結果、対局・検査・親継承記録。未着手の全候補一覧やPVを保存しない。
